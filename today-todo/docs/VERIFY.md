# 人工验收清单

照这个顺序点一遍，大约 6 分钟。每项都能用眼睛判断，不需要看代码。

## 准备

1. 双击 `E:\WorkBuddy\start.bat`
2. 记下窗口里 `[推荐]` 那一行地址
3. 电脑浏览器打开 `http://localhost:3000`
4. 手机连同一个 WiFi，浏览器打开 `[推荐]` 地址

## 清单

| # | 做什么 | 应该看到 |
|---|---|---|
| 1 | 点右下角的「+」，写下「买菜」，点「添加」 | 面板从圆形按钮连续长成卡片；提交后条目出现在列表最上方，未完成数 +1 |
| 2 | 再点「+」，什么都不写就点「添加」 | 面板内出现提示「先写一件要做的事」，不新增条目 |
| 3 | 点「+」后只输入几个空格再提交 | 同上，不会出现空行 |
| 3b | 点「+」后按 Esc 或点「取消」 | 面板沿原路收回成圆形按钮，输入内容保留到下次打开 |
| 4 | 勾选「买菜」 | 复选框变黑底黄勾，文字划线变灰，未完成数 −1 |
| 5 | 再点一次复选框 | 恢复未完成，数字 +1 |
| 6 | 点某条右侧的红色 × | 条目消失，底部出现「已删除 1 件 · 撤销」 |
| 7 | 点「撤销」 | 条目回到列表 |
| 8 | 点「撤销条」右侧的 × | 提示条消失 |
| 9 | 在**手机**上新增一条 | **电脑**页面 3 秒内自动出现这一条，不用刷新 |
| 10 | 在**电脑**上勾掉一条 | **手机** 3 秒内同步 |
| 11 | 刷新手机页面 | 数据还在 |
| 12 | 把窗口关掉（Ctrl+C），重新双击 start.bat | 数据仍在，页面照常 |
| 13 | 勾选一条后，看列表下方 | 出现「已完成的会在 24 小时后自动清理」 |
| 14 | 键盘：按 Tab 走一遍 | 焦点依次落在 输入框 → 添加 → 每行复选框 → 每行删除 → 撤销条，且每一步都能看见黑色焦点环 |
| 15 | 手机横屏、或把浏览器窗口拖窄 | 不出现横向滚动条，按钮不变形 |
| 16 | 电脑上把页面缩放到 200% | 文字变大但都能读，没有内容被切掉 |

## 验证 24 小时清理（不用等一天）

在 `E:\WorkBuddy` 打开终端，用极短保留时间启动一个临时实例：

```bash
DATA_FILE=E:/WorkBuddy/test/ttl-check.json PORT=3200 DONE_TTL_HOURS=0.0004 node server.js
```

1. 打开 `http://localhost:3200`
2. 添加「测试清理」并勾选完成
3. 等 2 秒
4. 看列表：这条应该已经消失，未完成的条目还在

验证完关掉窗口，删掉 `test/ttl-check.json` 即可。

## 打不开时

| 现象 | 先查这个 |
|---|---|
| 手机一直转圈、超时 | 电脑首次运行有没有点「允许访问」；没有就按 README 里的 `netsh` 命令放行 3000 端口 |
| 电脑能开、手机不行，且换了热点就好了 | 原网络开了客户端隔离（校园网常见），以后用热点 |
| 打开是旧内容 | 地址端口不对（可能跑在 3001），看窗口里最新打印的地址 |
| 页面显示「连不上服务」 | 电脑上的窗口被关了，重新双击 `start.bat`，再点页面上的「重试」 |
