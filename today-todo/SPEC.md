# SPEC.md · 今日待办

## 产品

一个只在本人电脑与手机之间使用的「今日待办」清单。电脑上跑一个本地服务，手机连同一 WiFi 打开，
两端读写同一份数据。不联网、不注册、不上传云端。

**核心用户任务**：想到一件事 → 立刻记下 → 做完勾掉 → 知道还剩几件。

## 用户与场景

| 项 | 内容 |
|---|---|
| 用户 | 本人（单用户，无账户体系） |
| 设备 | 手机（主要输入）+ 电脑（主要查看与整理） |
| 网络 | 同一 WiFi / 校园网；不要求公网可达 |
| 使用节奏 | 一天内多次短时打开，每次几秒到几十秒 |

## 核心流程

1. 电脑启动服务 → 终端打印两个地址（本机 / 局域网）
2. 手机打开局域网地址 → 看到当前清单
3. 点右下角「+」→ 容器形变为添加面板 → 写内容 → 点「添加」或 Ctrl/⌘+Enter → 条目出现在顶部，剩余数 +1
4. 勾选完成 → 条目划线降饱和，剩余数 −1
5. 删除 → 条目消失，底部出现「已删除 · 撤销」
6. 另一台设备在 3 秒内看到同样的结果

## 范围

### 必须实现

- 新增任务；`trim()` 后为空（含全角空格）不添加
- 勾选完成 / 取消完成
- 编辑任务文本（行内编辑，空白与超过 200 字被拒绝）
- 删除任务，并可撤销
- 剩余未完成计数，增删勾实时正确
- 数据持久化到磁盘，重启不丢
- 双端（电脑 + 手机）读写同一份数据
- 已完成任务 **24 小时内没有再次操作**则自动删除，且规则对用户可见
- 断连时给出可恢复的提示

### 明确不做

登录 / 多用户、标签、优先级、日历与重复任务、提醒推送、拖拽排序、
搜索筛选、导出、PWA 离线、深色模式、公网部署、扫码二维码、React / 打包链。

## 约束与关键假设

| 项 | 结论 | 影响 |
|---|---|---|
| 「今日」语义 | 只显示当天日期，**不跨天清空**（防丢未完成事项） | 数据带 `date` 字段，将来按日归档零迁移 |
| 24 小时清理口径 | 以「勾选完成的那一刻」为起点；取消完成即清空计时 | 完成任务不会无声消失，规则写在列表下方 |
| 单用户 | 无鉴权，靠局域网隔离 | 同网段内他人可访问，属已知限制 |
| 零依赖 | 只用 Node 内置模块，无 `npm install` | `node server.js` 即可启动 |
| 部署层级 | 本地可运行 + 手机同网访问；不含公网部署 | 公网需另行授权 |
| 浏览器 | Chrome / Edge / Safari 现代版本 | iOS Safari 真机行为见「未验证」 |

## 数据与接口

```js
// data/todos.json
{ "version": 12,
  "items": [ { id, text, done, doneAt, createdAt, date } ] }
```

`doneAt`：勾选完成时写入 ISO 时间，取消完成置 `null`；超过 24 小时仍为完成态即在下次读取时清除。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/todos` | `{version, items, doneTtlHours}`，读取时顺带清理过期项 |
| POST | `/api/todos` | `{text}` → 201；空白 400；超 200 字 400 |
| PATCH | `/api/todos/:id` | `{done}` 或 `{text}`，也可同时给 → 200；类型错 400；不存在 404 |
| DELETE | `/api/todos/:id` | 204；不存在 404 |
| GET | `/api/health` | 服务状态与局域网地址 |

## 未验证（不计为通过）

| 项 | 原因 | 影响 |
|---|---|---|
| iOS Safari 真机表现 | 无 iOS 设备接入，仅做了 16px 输入与 safe-area 适配 | 输入缩放与橡皮筋滚动需真机确认 |
| 屏幕阅读器实播 | 无 NVDA / VoiceOver 环境，只验证了语义与播报区结构 | 播报时序可能与预期有差异 |
| 校园网客户端隔离 | 用户当前网络可通（A7 已验证） | 换网络后可能需要改走热点 |
