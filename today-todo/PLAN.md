## 决策记录

| 决策 | 选择 | 理由 | 代价 |
|---|---|---|---|
| 后端形态 | `node:http` 手写，零依赖 | 4 个接口 + 静态托管约 150 行；Express 会引入 `npm install` | 需自己写 MIME、路径穿越防护 |
| 存储 | 单 JSON + 临时文件 rename 原子替换 | 单进程单写者、量级几十条；可直接用记事本查看 | 不适合高并发或多进程 |
| 双端同步 | 操作后立即拉取 + 可见时 3 秒轮询 | iOS 切后台会掐断 SSE，轮询失败模式更少 | 最坏 3 秒延迟 |
| 布局 | 手机单栏 / 平板卡片 / 电脑两栏 | 手机是输入场景、电脑是查看场景，两种构图分开设计 | 多一套断点样式 |
| 「今日」 | 不清空，只显示日期 | 自动清空会静默丢未完成事项 | 长期使用需要手动清理旧项 |
| 已完成清理 | 勾选后 24 小时无操作即删，读取时惰性执行 | 免定时器、免后台任务；规则可见 | 需停机也会在启动时补清理 |
| 删除保护 | 撤销条而非二次确认 | 删除高频且可逆，确认弹窗更烦 | 撤销条占据底部空间，需手动关闭 |
| 编辑入口 | 每行一个铅笔按钮，行内编辑 | 双击在触屏上不可靠；点文字会误触勾选；显式按钮对触屏和键盘都稳定 | 每行多一个 44px 控件，320px 下正文只剩约 135px 宽 |
| 编辑态布局 | 整行换成「输入框 + 保存 + 取消」，隐藏删除 | 保存/取消明确，避免编辑中误删；键盘 Enter/Esc 同样可用 | 行高与其他行略有差异 |
