# DESIGN.md · 今日待办

## Design Identity

一张**被钉在桌上的今日清单**：粗黑描边当结构，硬投影当"盖章"，饱和黄只用来标记主动作。
不做圆角、不做渐变、不做柔光。风格是新粗野主义，但**服从任务**：清单的主干永远是一列可扫读的行。

- 参考基线（只作质量参照，不复制）：Gumroad 改版期的 neo-brutalist 系统、`DolphinFisher/neo-brutalist-todo` 的交互模型。
- 明确拒绝：卡片墙、玻璃拟态、渐变、发光、无意义动效、把复选框做成胶囊。

## 视觉系统

### 色彩（语义优先，一个颜色一个职责）

| Token | 值 | 唯一职责 |
|---|---|---|
| `--paper` | `#F2EFE6` | 页面底色 / 左栏板面 |
| `--surface` | `#FFFFFF` | 清单区、输入框 |
| `--ink` | `#111111` | 描边、正文、投影 |
| `--accent` | `#FFD426` | **唯一主动作**（添加）、日期贴纸、撤销按钮 |
| `--danger` | `#FF4D2E` | **仅**删除与连接失败 |
| `--muted` | `#5B5649` | 次要说明文字、已完成态 |

规则：黄和红不互换；提示类文案不用黄色填充（避免与主按钮抢"强调"语义），改用纸色 + 描边。
所有正文/控件文字与背景的对比度 ≥ 4.5:1，由 `tools/contrast.js` 实测，不靠肉眼。

### 字体与字阶

系统字体栈（中文字体包动辄数 MB，且校园网不可靠）：
`"PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Source Han Sans SC", system-ui, sans-serif`

| 角色 | 值 |
|---|---|
| 报头 Display | `clamp(3.5rem, 15vw, 5.75rem)` / 900 / lh `.92` / tracking `-.045em` |
| 计数数字 | 移动 `2.75rem`，桌面 `4rem` / 900 / lh `.9` / `tabular-nums` |
| 任务正文 | `1.0625rem` / 500 / lh `1.5` |
| 说明文字 | `.8125rem` / 400–700 / lh `1.4`，不低于 13px |

动 `font-size` 一律用 `rem`，`letter-spacing` 一律用 `em`，`line-height` 一律无单位。

### 间距与形状

- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 40
- 描边：`2px`（行、小组件）/ `3px`（输入、按钮、外框、分栏线）
- 投影：`3px 3px 0` / `4px 4px 0` / `7px 7px 0`，**零模糊**
- 圆角：全局 `0`
- 按压：`translate(4px,4px)` + 投影归零，`80ms steps(2,end)`；减少动效时取消位移

## 布局：两端分别设计

断点来自内容，不来自设备名。

| 区间 | 结构 |
|---|---|
| `< 720px` 手机 | 单栏，边到边（无外框），报头独占上方；输入框与按钮上下堆叠，均 ≥ 60px 高 |
| `720–979px` 平板 | 单栏，白色纸张卡片（3px 描边 + 7px 投影），输入与添加同一行 |
| `≥ 980px` 电脑 | **两栏**：左栏 360px 板面（纸色，右侧 3px 分栏线）＋ 右栏清单区 |

### 电脑端（新增结构，不是把手机版拉宽）

```
┌──────────────────────┬─────────────────────────────────────┐
│ 今日                  │                                     │
│ 待办                  │  ☐ 把今天的会议纪要发给产品组     ✕  │
│ [10月23日 周五]        │ ─────────────────────────────────── │
│                      │  ☑ 买牛奶                           │
│ 1                    │ ─────────────────────────────────── │
│ 件未完成              │                                     │
│                      │                                     │
│ [ 写一件…        ]    │                                     │
│ [      添加       ]   │                                     │
│                      │                                     │
│ 已同步 20:44 · 本地   │                                     │
└──────────────────────┴─────────────────────────────────────┘
```

- 整张纸 `max-width: 1080px`，`min-height: calc(100dvh - 96px)`，居中
- 左栏 `display:flex; flex-direction:column`，页脚用 `margin-top:auto` 压到底
- 右栏留白 36–40px，行与行用 2px 横线，不加卡片、不加行背景
- 任务文本 `max-width: 62ch`，超长 URL 用 `overflow-wrap:anywhere`

### 手机端（保持单栏，收紧节奏）

- 报头上下留白收到 20px 左右，标题两行堆叠，日期贴纸与计数同排（`space-between`）
- 添加按钮独占一行、整宽，拇指可直接命中
- 行高 ≈ 66px，一屏可见 4–5 条
- 底部留 `env(safe-area-inset-bottom)`，撤销条压在安全区之上

## 组件与状态

| 组件 | 规范 |
|---|---|
| 日期贴纸 | 黄底、2px 描边、3px 投影、`rotate(-2deg)`，只做装饰不承载交互 |
| 计数 | `aria-live="polite"`；数字 `tabular-nums`，增删即时变化 |
| 输入框 | 白底 3px 描边 4px 投影，**17px**（≥16px 防 iOS 聚焦缩放），`aria-describedby` 指向提示区 |
| 添加按钮 | 黄底黑字，唯一主动作；提交中 `disabled` 防重复 |
| 复选框 | 原生 `input[type=checkbox]` + `appearance:none`，27px 视觉框、44px 命中区；选中＝黑底黄勾 |
| 编辑按钮 | 白底黑铅笔，44×44，中性色，不与红色删除抢注意力；`aria-label="编辑：<任务>"` |
| 编辑态 | 整行换成「输入框 + 保存 + 取消」，隐藏删除按钮以免误触；保存为黑底白字（该行当时唯一的主动作），取消为白底 |
| 添加面板 | 同一个容器：收起是 64×64 圆形 FAB（半径 32），展开是 470×300 面板（半径 28）；窄屏宽度收敛为 `100vw - 32px` |
| 删除按钮 | 红底黑叉，44×44，常驻可见（不依赖 hover），`aria-label="删除：<任务>"` |
| 空状态 | 2px 虚线框：说明这是什么 + 下一步做什么 |
| 清理说明 | 仅在存在已完成任务时出现在列表下方，13px 次要色，说明 24 小时自动清理 |
| 提示条 | 纸色底 + 2px 描边（不用黄，避免抢主动作） |
| 撤销条 | 删除后固定底部，`role="status"`，**不自动消失**，含「撤销」与「关闭」 |
| 离线横幅 | 红底，`role="alert"`，含「立刻重试」，文案说明去哪检查 |

状态覆盖：loading / empty / populated / done / focus / hover（仅 hover 设备）/ error / offline / undo。

## 交互

- 新增：点右下角「+」→ 同一容器从 64×64 长成 470×300 面板（半径 32 → 28），里面是**多行文本框**；Ctrl/⌘+Enter 或点「添加」提交，Esc 或点「取消」收回
- 勾选：即时改样式与计数，请求失败回滚并提示
- 编辑：点铅笔进入行内编辑，Enter 或「保存」提交，Esc 或「取消」放弃；编辑期间暂停整表重绘，避免轮询打断输入
- 删除：立即执行 + 撤销条（可逆优先级高于二次确认）
- 已完成：勾选后开始计时，24 小时内没有再操作即被清理；列表下方常驻一句规则说明，避免任务无声消失
- 同步：操作后立即拉取 + 可见时 3s 轮询 + 回到前台立即拉取；连续 2 次失败才显示离线横幅
- 键盘：Tab 顺序 = 输入 → 添加 → 各行复选框 → 各删除 → 撤销条；焦点环为 3px 实心黑环 + 3px 留白

## 动效

只有一个形变，其余交互一律即时反馈（80ms 按压位移属于状态反馈，不是动画）。

| 项 | 值 |
|---|---|
| 载体 | **同一个容器**，不是两个元素互换 |
| 尺寸 | 64×64 → 470×300（窄屏宽度收敛为 `100vw - 32px`） |
| 圆角 | 32 → 28 |
| 曲线 | `cubic-bezier(.2, .9, .22, 1)` |
| 时长 | 480ms |
| 内容入场 | 容器落定后才开始，每项间隔 4 帧（66ms）：0 / 66 / 132 / 198ms，透明度 + 4px 上移 |
| 关闭 | 沿同一条曲线反向收回 FAB 原位，内容立即消失 |
| 减少动效 | 过渡时长降到 0.01ms，交错延迟归零 |

实现要点：先把容器按 FAB 的实测矩形落位（`getBoundingClientRect`）并强制重排，再写入目标尺寸，宽高才会真的走过渡；直接改 class 会因初始值未生效而瞬间跳变。

## 视觉基线（Freeze 后不随意改）

1. 全站零圆角、零渐变、零模糊投影
2. 黄色只出现在主动作、日期贴纸、撤销按钮
3. 红色只出现在删除与连接失败
4. 每屏只有一个主按钮
5. 电脑端两栏、手机端单栏，不靠同一套比例硬撑
