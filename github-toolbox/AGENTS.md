# Personal GitHub toolbox

Read README.md and INSTALL.md before installation or maintenance. This directory
preserves the owner's Windows usage profile, not an upstream release workflow.
Keep upstream attribution, licenses, source commits and checksums. Never publish
passwords, cookies, downloaded media, desktop screenshots, logs or MCP evidence.
Do not test against E:/GitHub灵感 or change existing desktop shortcuts or global
Agent configuration. Restore into a new directory. REA setup, MCP registration,
Winhance system changes and desktop shortcuts are separate explicit actions.
Do not replace locked versions with latest after a checksum failure.
Run python -m unittest discover -s github-toolbox/tests -v and the root repository
check before publishing. Update snapshots through scripts/export_profile.py;
never put node_modules, .next, .git, local .env files or running service state in
the source snapshot. Preserve .env.example and upstream license files.
