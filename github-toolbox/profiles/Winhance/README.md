# 我的 Winhance 使用入口

固定 v26.06.12 安装包，从原发布者下载并校验。本机目录还存在解压后的便携运行文件；未找到可以作为个人配置发布的导出文件，因此本合集保留使用方法与安装来源，没有编造系统优化预设。
