# usage · 本机便携候选

额度、快捷文本与每日提醒。此包作为未签名的个人使用候选归档。

## 启动

目标系统：Windows 10/11，64 位。完整解压整个目录，再双击 **usage.exe**。运行环境已经包含在包内，不需要安装 Python 或开发工具。首次出现 Windows 安全提示时，请先核对你收到的文件来源与校验值；此候选未做发行签名。

不要单独移动启动文件，也不要在压缩包里直接运行。数据默认保存在 `%USERPROFILE%\.usage`，不在便携目录里。第二次启动恢复已有浮窗，文件锁禁止新建第二个运行实例。首次升级会完整复制同一产品的既有配置、正文和提醒账本；旧目录保留，不需要重输密钥。如果发现多份已配置数据则停止导入，避免自动混合。

## 使用

- 鼠标进入贴边小球后展开；停在 Codex 或 GLM 上看双窗口明细，移出后自动收起。拖动小球或叶片空白，可贴到四边或放在桌面中间。
- C/G 表盘分别显示该平台 5h／周中较低的已知额度。H 表示 5h，W 表示周。未知、旧值和故障都有文字提示；DeepSeek 保留余额含义。
- 设置球或托盘菜单打开设置。设置是普通窗口，其他应用可以覆盖它。
- “快捷文本”可添加具名文本、设置六个常用复制位。“更多文本”可复制其余条目。用系统记事本编辑正文，按 Ctrl+S 保存；复制读取已经保存的内容。“重新读取正文”用于手动刷新保存文件。
- “每日提醒”按本机时间安排。应用退出或电脑睡眠期间不保证送达；同日恢复只补发一次当日未领取事项。打开列表不会清除未读，需点击“全部标为已读”。
- “账户”在本机输入 API Key，密钥存入当前 Windows 用户的凭据管理器。不要把密钥发送到聊天。
- “窗口行为”可设置减少动态效果、固定展开和开机启动。开机启动只有在你明确勾选并保存后才注册。

开机启动指登录当前 Windows 用户后启动，系统可能延迟执行。启用后使用当前目录的 `usage.exe`，数据目录保持与日常启动一致；移动或更新便携目录后，请重新保存一次开机启动设置。若在 Windows“启动应用”中禁用过该项，也需在系统中重新启用。保存会通过真实桌面会话核验启动项，不需要管理员权限。

托盘提供找回浮窗、隐藏、刷新与退出。窗口获得焦点后，可用 Tab / Shift+Tab 导航、Enter / 空格执行动作；Ctrl+P 固定展开，M 切换减少动态效果，R 重新读取额度，Ctrl+Q 退出。

## 账户与验收边界

Codex 需要本机已安装、已登录官方 Codex；只读取额度，不发送模型请求。便携包不携带你的密钥、配置、文本正文或账户数据。

三家只读查询及参考账户值已在当前设备对照。GLM个人版同类型的5h／周窗口按已验证身份区分，未返回的恢复时间保留未知；其他套餐或未来结构变更不会被强行解释为当前窗口。

应用显示名为 usage；本机数据目录和凭据的内部标识沿用原项目代号，保留已有保存内容。原有四个绑定保留，第五／第六位可在设置中另行配置。旧四位候选不能读取已配置第五／第六位的数据，应使用当前六位候选。

参考设备为一块原生 150% 显示器，其他缩放为渲染模拟。混合 DPI、多屏拔插、真实休眠、无开发环境的干净 Windows 和长时间驻留仍有验收门槛。此候选不代表全部产品 Done 或正式发布。

## 备份、恢复与移除

见同目录 `SOP.md`。损坏或较新版本的配置不会自动覆盖；启动失败会显示错误并提供打开数据目录的入口。退出应用后再备份数据。配置备份不包含 Windows 凭据中的密钥，也不包含已经删除的文本正文。

随包组件和许可见 `THIRD_PARTY.md`、`licenses` 目录。`build-manifest.json` 记录构建来源，`SHA256SUMS.json` 记录随包文件校验值。整个压缩包的校验值由交付记录提供。
