# 本机运行与恢复

## 使用便携候选

完整解压整个目录，再双击 `usage.exe`。不要只复制启动文件。需要打开设置时，点击浮窗的设置球或托盘菜单。便携包携带运行环境，不需要安装 Python 或开发工具。

设置包含快捷文本、每日提醒、账户、窗口行为。设置窗口是普通窗口；其他应用可以覆盖它。叶片和其紧邻操作面板仍保持桌面工具的层级。

主浮窗每2秒低频核对实际窗口层级；被普通窗口错误覆盖时自动恢复，不激活、不移动，主动隐藏到托盘仍保持隐藏。若托盘图标在但球不可见，请先保留现场：不要重启、重复启动或删除数据；记录时间并检查主窗可见、最小化、位置与实际Z序。日志中的`window_layer_restored`表示执行过层级恢复，不代表已证明外部触发原因或长期稳定。

正文在系统记事本中按 Ctrl+S 保存。自动预览未更新时点“重新读取正文”；复制总是读取已经保存的文件。未保存的标签页修改不会进入剪贴板。

提醒按本机时区安排。应用退出或电脑睡眠期间不保证送达；同日恢复只补发一次当日未领取事项。打开提醒列表不会自动标为已读；点击“全部标为已读”清除铃铛。系统通知提交成功不等于用户已经看见。

## 账户

在账户区本机输入 GLM / DeepSeek API Key。密钥进入当前 Windows 用户的凭据管理器，输入后清空，不在配置中保存密钥正文。无需把密钥发送到聊天。

Codex 读取官方本机登录上下文，需已安装并登录官方 Codex。它只查询额度，不发送模型推理请求。GLM 尚未经真实响应与官方界面核验的字段显示未知；不能凭界面正常运行宣称数据已核验。

改密钥会建立新 accountId，旧快照不会用于新账户。旧本机凭据或缓存清理失败时，会显示重试清理入口。只清理此应用拥有的旧引用；不会清理其他应用的凭据。

额度正常刷新间隔：收起／展开均为 5 秒，从上一次成功响应完成后计算。失败继续按 30／60／120／300 秒退避，并遵守平台 Retry-After；鉴权失败暂停，重新配置授权后恢复。界面倒计时本地计算。

Codex桌面更新可能替换版本化CLI目录。默认读取器在原程序消失后自动重新发现；暂时缺少CLI走上述失败退避，程序恢复后继续读取，不要求重配账户。真实授权失败仍保持暂停。明确指定CLI路径的维护检查不会自动替换为其他程序。

## 数据位置与备份

默认目录：`%USERPROFILE%\.usage`。从Codex和资源管理器启动均使用同一物理目录。首次升级自动完整复制现有usage数据（包括此前被重定向至Codex LocalCache的配置）；原目录保留为备份，凭据仍在Windows凭据管理器。已有目标配置、损坏／较新配置不会自动覆盖；发现多份已配置来源则停止导入，用`--data-dir`明确选定。

- `config.json`：账户引用、快捷文本元数据、提醒定义、窗口行为。
- `config.json.bak`：上一次成功写入前的配置备份。
- `snapshots.json`：最后成功查询的脱敏数据及时间。
- `snippets\<id>.txt`：各条文本独立正文，UTF-8，最大 1 MB。
- `reminder-ledger.json`：最近 30 个本地日期的提醒去重与未读记录。
- `logs\events.jsonl` 与一个轮转副本：每个至多 256 KB 的诊断事件，只记录事件种类（含窗口层级恢复）、平台、错误类型和代码位置；不记录窗口标题、其他应用身份、密钥、正文、剪贴板、原始响应或异常消息。

先从托盘退出应用，再复制整个数据目录进行本机备份。配置备份不包含已删除正文，也不备份 Windows 凭据中的 API Key。回退配置后如旧密钥引用已清理，需要在账户区重新输入密钥。

损坏或来自较新版本的配置不会自动覆盖。启动失败时会显示中文错误，提供打开数据目录的入口。请先保留原文件；不要删除全部数据来掩盖损坏。来自较新版本的配置应由相应版本打开。

要明确恢复上一次配置，先退出应用并备份当前目录，在 **Windows PowerShell，便携包根目录**运行：

```powershell
.\runtime\python.exe .\app\repair_config.py --restore-backup
```

开发环境则使用：

```powershell
.\.venv-win\Scripts\python.exe src/repair_config.py --restore-backup
```

恢复工具验证备份后，保留当前配置的独立副本，再恢复；不会回退较新版本，也不修改提醒去重记录或密钥。

## 停用与移除

开机启动在登录当前 Windows 用户后执行，系统可能延迟运行。在“窗口行为”勾选并保存后，应用通过 Explorer 桌面会话写入并读回当前用户的启动项，避免启动父进程的 MSIX 注册表重定向。便携环境注册当前 `usage.exe`；移动或更新便携目录后重新保存。若 Windows“启动应用”中曾手动禁用该项，需在系统设置中恢复。读写或核验失败会显示错误，不会显示保存成功。读取与保存开机启动设置时显示进度，设置分区仍可切换；只有核验完成后才确认保存成功。

如已启用开机启动，先在“窗口行为”中取消并保存，再从托盘退出。随后可删除便携目录；用户数据保持原位。要移除账户密钥，先在账户区逐家断开，并完成待清理项；仅删除目录不会删除凭据。删除数据目录前请自行保留需要的正文。

本机候选尚有账号、显示器、干净 Windows 等验收门槛，见同目录 [README.md](USAGE.md)。`build-manifest.json` 标识当前包的来源；开发工作区另外提供完整验收记录。候选构建不注册开机启动，也不公开发布。
