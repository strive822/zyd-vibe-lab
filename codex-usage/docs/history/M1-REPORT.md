## 实现范围

- Windows 11 上的 PySide6 透明异形顶层窗；原版右侧露出约 24 DIP，当前 A44 候选露出 44 DIP。展开窗口固定 300 × 260 DIP，叶形路径实测包围框约 213.2 × 212.1 DIP。时间详情不改变窗口外框。
- 温白叶形、近黑数字、橄榄色选中、细分隔线；上方固定时间槽，下方“5h/周 × Codex/GLM”对照表，DeepSeek 独立余额基线。五个同笔画语法的卫星球按序出现与反向回收。
- 固定演示数据和正常、加载、空、错误、旧数据、未连接六类状态。默认、Codex/GLM/DeepSeek 详情共享时间槽；GLM 周恢复未知明确显示未提供，DeepSeek 不显示虚构的配额重置。
- 第一颗具名复制球接通固定文本；剪贴板回读匹配后，叶片内的时间槽短暂显示“复制完成 / 需求澄清 / 已写入剪贴板”，复制球同步变成对勾，1.8 秒后恢复原详情。提醒球另接 M1 的未读视觉触发/清除演示，不进行调度或通知；其他三球仅呈现布局和反馈。
- 100 ms 悬浮意图、130 ms 平台意图、700 ms 离开等待；从当前进度反转；减少动态效果；Tab/Enter/Esc 和点击入口。
- 三单位倒计时、借位和位数变动、24h 模式切换、到零待确认。演示时钟以 2026-09-27 02:10（Asia/Shanghai）为起点，随运行单调递进，不接网络。

## 当前风险与 Freeze 边界

1. 本机 Windows Computer Use 辅助工具在初始化时返回 `sandboxCwd is not a local file URI: file:///<workspace>`。用户已亲自操作 Codex/GLM 悬浮与复制，但尚未系统验收完整跨空隙指针路径、透明空白点穿透桌面、悬浮时不抢焦点、真实提示层与多屏混合 DPI；不能凭 Qt mask 的程序化断言宣称它们已通过。
2. 原版收起球仅有 24 DIP 可见宽度，用户实测难辨。当前 A44 候选外露 44 DIP、采用 C/G 双表盘、G/¥ 旁独立“半”字和 `¥` 余额标记；提醒铃为独立状态。用户已确认“半”字原尺寸可读，整体额度盲测、提醒语义和浅/深桌面识别度仍需独立审查。
3. 100% 渲染的时间文字与表格密度接近下限；尤其双窗口详情和 DeepSeek 基线需要在真实桌面背景与正常观看距离判断。辅助技术目前只有窗口级名称/说明，逐动作的可访问名称与原生焦点行为尚未设备验证。
4. Qt 窗口遮罩在 Windows 11 当前设备可创建，窗口像素渲染可抓取；`QScreen.grabWindow(winId)` 对透明窗口返回黑图，故证据使用 `QWidget.grab()`。这不证明桌面合成截图、阴影和透明点击的实际效果。
5. 用户已在当前 150% 显示器上确认复制反馈、粘贴动作、GLM 与 Codex 详情的更新时间和“秒”字完整，也确认收起球与叶片外轮廓统一、边缘平顺。整体观感、收起球语义、跨空隙指针路径、桌面点击穿透及混合 DPI 仍需独立验收。不记录 UI Freeze，不扩展其他页面。

建议独立 Design Critic 重点审查：100% 的中文/数字字距与双倒计时辨读、叶形上缘/右缘/底部余额的安全留白、半球状态编码、五球图标的动作辨识、从 Codex 详情斜向到复制球的指针路径、出入场节奏以及键盘焦点与鼠标选中的区别。
