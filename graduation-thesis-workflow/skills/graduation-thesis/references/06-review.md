# 全文真实性与一致性审查

读取完整稿、需求、证据表、文献笔记和原始结果。优先逐项核验核心贡献和所有数字/引语，然后检查其他论断。审查报告写 `reviews/final-review.md`：范围、实际核验操作、发现的问题、修正、尚存局限，不生成空泛“全部通过”。

必须检查：

- 学校必需项是否都有实际产物，引用样式/篇幅是否按学校口径检查。
- 正文每个引文是否在文献表，文献表是否存在未引用条目（按学校允许方式处理）。作者、年份、版本及 DOI 是否准确。
- claims 是否覆盖正文核心论点、数字和引语；不能靠漏登记来通过机器检查。
- metadata/abstract/fulltext 范围是否足以支撑具体句子，原文定位是否存在，全文获取是否确实发生。
- 表格、图、摘要、正文与结论中的结果能否从保存的材料重新计算或核对；重算与原文差异是否解释。
- 问卷、访谈、审批、实验记录是否实际存在；用户提供材料的独立核验边界是否如实写明。
- 局限、负结果和反例是否保留；因果、显著性、泛化与创新声明是否超过证据。
- 原文引用、改写、第三方图片的署名与使用条件是否按要求处理。不能用自动生成的“查重报告”冒充真实检测。

报告局限必须可见：哈希只检测文件变化；网站记录不能保证论文无误；AI 审查不能认证研究诚信。若无另一位审查者可用，进行独立的第二遍阅读并明确仍是同一代理，不假装外部专家评审。

内容修改后作废受影响交付物的旧哈希与审查结论，重新检查。未解决的问题登记 blockers，禁止标 complete。学校/导师实际签核只由实际反馈支持，不由本模块代签。
