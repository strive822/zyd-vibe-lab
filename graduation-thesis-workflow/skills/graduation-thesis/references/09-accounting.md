# 会计专业：按题目选择，不默认实证回归

只有会计、财务、审计类题目涉及以下任务时读取。先判断学校认可的论文类型：企业案例、财务分析、实证研究、规范研究；不因专业名称自动套用因果推断。

- 企业案例：优先公司公告、交易所披露、年报及监管原文。逐个数字记录企业主体、合并/母公司口径、期间、币种、单位、年报页码、重述情况；不能把新闻转述当审计结论。
- 财务分析：保留原始报表和取数表，写出指标公式，说明平均余额/期末余额、不同年度会计口径及可比性。所有结果由实际数据计算，无法取数时留缺口，不能补“合理值”。
- 实证研究：登记样本来源、期间、筛选、变量定义、缺失处理及清洗代码。CSMAR、Wind 等若无授权，说明限制；公开替代来源必须评估覆盖与口径，不能假称等价。
- 只有研究问题和识别条件成立时才考虑 DiD、IV、RDD 等方法。明确识别假设、检查及不能检验的部分；普通相关性回归不能写成因果证明。不以结果显著为准选择样本或模型。
- 规范研究：核对适用地区、准则版本、生效时间及原文条款。事实、规则解释与作者建议分开。不能用过期准则解释现行要求而不披露。

复核时从正文选择每个关键数字，沿“正文/图表 → 分析输出 → 计算脚本 → 取数表 → 年报页码或数据库导出”回溯。无法回溯的结论不得标为 supported。助手不能代替实际审计或学校导师确认。
