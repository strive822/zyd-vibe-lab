# 真实文献检索与阅读

以研究问题和学校要求制定检索计划，再按[来源目录](sources.md)选择权威学术数据库、出版社和机构仓储。用宿主实际可用的工具打开条目。中文课题优先查知网、万方或国家哲学社会科学文献中心，国际资料选学科数据库。无 DOI 的论文、书籍和档案可用正式馆藏、出版或数据库记录核验。

## 检索与筛选

1. 把研究问题拆成主题词、同义词与中英文术语。记录实际检索式、数据库、日期、学科与时间范围、文献类型、筛选条件和结果，保存在 `literature/search-log.md`。核心主题使用另一个适合的入口补查，或对核心文献做前向、后向引用追踪。入口受限时记下原因、替代来源和覆盖缺口。
2. 按相关性、版本、研究方法及学校要求筛选，保存有意义的纳入与排除理由。优先使用能直接回答问题的原始研究；用综述定位争议、代表作和其他研究。按 DOI、数据库永久标识或题名、作者、年份去重，保留预印本、学位论文和正式发表版本之间的关系。一般综述的记录粒度与课题相称，系统综述还需保留各库完整检索式、筛选数量及全文排除理由。

## 可执行检索

技能内 `scripts/literature.py` 提供不需要密钥的 Crossref 元数据检索与 DOI 查询，使用 Python 标准库。

```text
python <技能目录>/scripts/literature.py search "主题关键词" --limit 10 --out <项目目录>/literature/search-001.json
python <技能目录>/scripts/literature.py doi "10.xxxx/实际DOI" --out <项目目录>/literature/doi-001.json
```

示例 DOI 是占位格式，不是文献。脚本只访问 Crossref 固定 HTTPS 端点，不下载全文、不执行网页内容，不把候选项自动写成已验证引用。响应原文及时间、查询 URL、哈希一并保存。实际网络失败要报告，不用记忆生成假响应。

## 从候选到引用

1. 打开具体出版页、数据库条目或机构仓储记录，核对题名、作者及顺序、年份、刊名或出版社、卷期、页码或文章号及标识符（按文献类型）。核心来源有可用的独立记录时，再对照 DOI 注册机构、另一数据库、馆藏或正式版本核验。DOI 解析成功仍须核对是否指向同一篇；冲突无法解释时留在候选区。
2. 从出版页、Crossmark 或权威索引的关联通知检查版本、更正、撤稿、撤回和关注声明。已更正的文献按核对过的当前版本引用，并记录更正对论点的影响。已撤稿、撤回、存在关注声明或出版状态无法核实的条目暂不作为论据；需要讨论事件本身时，以实际公告为证据。对早期纸本等缺少在线更新服务的资料，以权威馆藏或原出版记录核对，说明可查范围。
3. 阅读能合法取得的原文，按[证据协议](contract.md)登记。仅见书目可确认书目信息，仅见摘要可引用摘要明确报告的事实。需要方法细节、精确数字、直接引语、图表或结论限定条件时，找到原文相应位置。不能取得全文时换用能支撑相同论点的合适来源，或把缺口留到有授权材料时再补。
4. 维护 `literature/references.bib` 或学校要求的引用库，使用从来源核对过的书目。按证据和定位整理综述矩阵，记录问题、方法、样本或材料、发现、局限、分歧及与本题关系。只有在检索覆盖和实际证据允许时才写研究空白。

检索不足时继续有依据章节，报告缺口。不要假装可以访问知网/万方订阅全文；可请用户通过已有授权提供文件。禁止绕过登录/付费墙；不把未公开题目或敏感材料原文发到公开检索服务。

## 可复核的证据笔记

每篇纳入文献建立独立笔记，保留书目、条目与所读版本、访问日期、实际读取范围、出版状态核对结果和链接、相关论点及原文定位、局限和未取得部分。出版方与数据库记录冲突时记明采信依据。区分原文报告、自己的解释和待验证推测；直接引文保留对应原文及定位。

一个论点引用多个来源时，claims 的 locator/rationale 按 evidence id 逐项说明各自定位与支持范围。没有定位的来源只能留在候选列表。不同来源相互矛盾时保留分歧，不以多数摘要代替判断。检索日志保留纳入/排除原因；数量与题目和学校要求相称，不预设必须凑够几十篇。
