# 研究执行与可复现记录

依 research-plan 执行，不先写结果再补实验。新建 `runs/<run-id>/` 保存方法版本、命令/操作记录、输入证据 id、环境、参数、种子（适用时）、起止时间、退出状态、原始输出和分析脚本。实际仪器/问卷采集由具备条件的人执行，AI 只处理真实取得的资料。

原始材料置于 `data/raw/`，不得覆盖。清洗后的数据和排除记录单独保存，保持从原始材料到论文数字的追溯路径。用户提供数据的真实性无法独立验证时，记录“用户提供，未独立核实采集过程”，不得写成 AI 已确认真实采集。

统计方法按设计及数据条件选择；检查样本量、缺失、异常、独立性和适用假设。不能使用任意阈值自动宣布有效。定性分析保存编码到原文的对应。理论工作保留推导和适用前提。系统测试保留失败案例。

图表必须由保存的数据/分析代码生成或由可定位原始材料支持，记录图表 id 和来源。禁止用图像生成模型画出假统计图、显微图或实验照片。概念示意图可绘制并注明示意。

重复失败应诊断并修改合理实现；对研究方法的实质变更写入 DECISIONS。重大变更重新确认。预算不足或真实材料缺失时记 blockers，继续无依赖工作。

每个关键结果登记为 evidence，写明文件、哈希、取得方式及局限。不要只保存一个手工填写的“成功”表格。结果文件和项目代码可复用，个人数据不公开进工作流仓库。
