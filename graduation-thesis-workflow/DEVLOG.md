## 2026-09-10 · v0.1.0 初始搭建

根据使用者确认：公开可复用、覆盖各专业入口、按学校确定交付物、确认需求后自动推进、绝不编造文献与研究材料。

完成一个自包含技能、七个阶段模块、五类方法分支、证据与状态协议、公开来源目录；实现初始化/检查/哈希、Crossref 查询与三个平台 ZIP 打包脚本。补充安装、发布、许可与维护文档。

采用官方技能结构说明并使用标准库，不复制来源或许可证未核实的外部技能。已有 humanizer 可以在用户环境可用时选用，但不参与真实性判定。

第一轮 14 项离线测试通过。Crossref 实际联网检索成功返回 2 条元数据候选；未读取全文。源技能静态验证通过，Windows 下需用 -X utf8 运行上游验证器。

最终 18 项回归全部通过，新增网络失败无伪造输出、检索不升级为全文、已有检索文件不覆盖、技能内链接完整性检查。三种 ZIP 已生成并附 SHA256 清单；Codex 与 Claude Code 包内容相同，WorkBuddy 包增加专用元数据。未执行原生客户端端到端论文验证或 GitHub 发布。
