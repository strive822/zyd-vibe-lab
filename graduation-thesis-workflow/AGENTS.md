# Repository maintenance

This repository contains a reusable thesis workflow, not a user's thesis project.
Keep the canonical bundle in skills/graduation-thesis. Build platform packages with scripts/package.py; do not hand-edit generated ZIPs.
Never label synthetic test fixtures as research evidence. Never promise graduation or absence of model errors.
Keep private thesis materials, credentials and paper full texts outside the public repository.
For changes to scripts run python -m unittest discover -s tests -v. For workflow changes review the evidence and missing-material behavior. Update README, DEVLOG, DECISIONS, GOTCHAS and SOP when relevant.
