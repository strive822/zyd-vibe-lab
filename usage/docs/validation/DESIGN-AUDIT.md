独立临时多窗口试验中有即时抓帧内容不完整的截图，未作为产品缺陷或通过证据；稳定正式 CLI 重新捕获部分未知态后，标题、表头、读数和余额完整。复制成功的动作结论来自实际键盘事件与剪贴板回读；11-copy-feedback-stable.png 只是已验证结果的稳定视觉状态示意。

Computer Use 初始化仍因 sandboxCwd WSL 路径错误失败，本轮没有独立物理鼠标重测。审查已检查本候选的送审原生桌面帧及其记录，送审包记录用户物理复制与顶部提醒正常；较早哈希的四边录屏不算当前候选完整四边重测。混合 DPI、多屏接缝与完整生产页面仍由后续里程碑验收。模拟、Qt 键盘事件、原生命中与用户物理反馈保持各自证据边界。

## 必须保留

- 叶形与收起球的单轮廓交接、安静的常驻表盘与固定五球操作顺序。

- Codex／GLM 固定位置、DeepSeek 独立金额、可信度标记优先于优惠。
