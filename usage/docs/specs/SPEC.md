## 1. 产品定位与任务

一个常驻 Windows 桌面的个人工具：用很小的空间查看 Codex / GLM 额度和 DeepSeek 余额；靠边后变为有信息的小球；悬浮展开后，中心读数据，外围半圈小球执行快捷操作。

目标用户是同时使用这三家服务、希望少切换网页的个人用户。第一版每家一个账号。核心任务按优先级排列：

1. 一眼判断哪家还能用、额度何时恢复、当前数据是否新鲜。
2. 不离开当前工作流，复制一条有名字的预存文本。
3. 判断 GLM / DeepSeek 当前是否处于常态优惠时段。
4. 每天在自己设定的时间收到事项提醒。

待实测的体验目标：已熟悉布局的用户能在 2 秒左右找到指定额度、余额或状态；核心复制操作从展开到完成不超过一次点击。它们是验收目标，不是已完成的用户研究结论。

## 4. 显示语义

### 4.1 平台额度与数据更新是两件事

- “重置 / 补回”：平台配额恢复。显示绝对时间和倒计时。
- “更新”：本工具成功取得数据。记录每个平台自己的最后成功时间。
- 正常时底部可显示三家中最早的最后成功时间，标为“数据截至”；不可把某一家刚成功的时间冒充全部更新。
- 单家异常直接在该家行显示“更新失败 · 保留 HH:mm 数据”；底部不再显示统一成功。
- 默认展示“剩余”；Codex 的 usedPercent 是已用，必须转换后再显示。
- 不将 Codex 百分比推算为固定 Token 数；GLM 积分也不等于 Token 数。
- 倒计时在本地计算，不为了数字走动持续联网。到点只显示“待确认”，不能自行把额度重填到 100%。
- GLM 官方描述五小时额度为动态恢复。在验证数据前，不承诺“一个时刻全部补满”。可显示“下次补回”；来源未知则显示“恢复时间未提供”。
- 无额度数据、未登录、无此窗口、余额为零是不同状态。

### 4.2 常显概要与悬浮明细（用户已确认）

概要保留 Codex 与 GLM 的五小时/周剩余量、DeepSeek 余额、独立优惠标记、必要的异常/旧数据提示。正常概要不同时堆叠所有日期和倒计时。

指向下方某个平台概要列的列名、五小时/周剩余量或列内留白（DeepSeek 为余额行），或键盘聚焦同一区域后，先出现区域强调，再淡入它的时间明细（在叶形内部的固定时间槽中替换）：五小时恢复时间与剩余时长、周恢复时间与剩余时长、该平台最近成功更新时间。DeepSeek 只显示更新时刻、余额组成和适用优惠解释，不生成配额重置。没有来源的字段显示“未提供”。

常态上方从 Codex／GLM 的 5h 与周共四个额度窗口中，选剩余百分比最低的已知窗口；未知不当作零，平手时先选 5h、再选 Codex。标题标明被选平台与窗口，百分比为主读数，三单位倒计时并列作补充；没有恢复时刻时明确写“未提供”，仍展示该窗口的剩余百分比。DeepSeek 是金额，不参与百分比排序。“恢复 03:40”是绝对恢复时刻，“更新 02:09”是最近成功取得该家数据的时刻。指向平台后，同一时间槽替换为该平台的双窗口详情，概要保持原位。

收起球的 C/G 两枚表盘分别取该平台 5h 与周中最低的已知剩余，表盘中心用 H（5h）或 W（周）标明所取窗口。两窗均未知时为断续环加问号；只有一个窗口已知时显示该已知窗口，展开后仍明确展示另一个窗口未知。展开时表盘移向对应的 5h 半弧或周轨，不能让周额度表盘无解释地变成 5h 图形。常态优惠分别用贴近 G 和 ¥ 的单字“半”提示，展开后写明“半耗”和“半价”；这不修改额度或余额数值。

所有平台概要在查看明细时仍可见。内部明细区不移动其他平台或外围按钮；鼠标移到注释上能继续阅读，不形成追赶指针的浮层。鼠标只靠悬浮查看，点击平台数据或叶片空白不锁定展开态，移出后按延时自动收起；键盘聚焦仍可查看相同信息，Esc 返回。尺寸、延时和动效见 DESIGN；以真实小尺寸原型验证。

### 4.3 三单位倒计时与数字变化

用户已选择自适应三单位。初始分界采用 24 小时：剩余时间大于或等于 24h 时显示“天 / 时 / 分”；小于 24h 时显示“时 / 分 / 秒”。两个窗口各自按剩余时长选择单位，同屏可分别为时/分/秒和天/时/分。首个数值不补零，后两个数值固定两位；零值单位也显示，例如“0时01分05秒”。

例：“3天00时00分”“1时30分00秒”。跨 24h 从“1天00时00分”整体切到“23时59分59秒”；跨 10h 从“10时00分00秒”变为“9时59分59秒”，消失的位也要有动效。所有单位/数字使用固定槽位，变化不推动相邻数据。

数字位更新采用短距离滑动和透明度变化；单位制变化按整个三元组成组切换。到零保留“0时00分00秒”并标“待确认”，不自动恢复额度；来源未给时间则显示“未提供”，不能当作零。

## 6. 关键操作定义

### 6.1 贴边与展开

- 自由位置保持信息可见；贴边后才启用自动收起。固定展开是单独开关。
- 支持左、右、上、下四边，按可用空间向屏幕内部展开；屏幕角落只选择一条边。
- 首版不自动吸附多显示器之间的接缝；只用可用工作区的外边缘，避免鼠标跨屏误触。
- 参数：贴边阈值 12 DIP；悬浮小球/半球约100ms后开始；中心展开约220ms；当前七个功能球在既定280ms总入场跨度内错峰，四边位置见 DESIGN 第11节；整体移出等待700ms、缩回约180ms。五球原节奏保留于 M1 演进记录。
- 功能球从靠近主体外缘的各自位置沿短路径舒展至半圈落点，伴随淡入和轻微缩放；收起时反向回收，途中返回从当前进度反转。球到位后接受点击，完全隐藏的球不截获桌面输入。完整节奏见 DESIGN 第6节。
- 平台悬浮意图暂定 130 ms；区域强调约 90 ms，明细淡入并位移不超过 6 DIP、历时约 170 ms。功能球入场到位后的悬浮反馈约110ms；半圈落点和命中区域固定。
- 明细收回与整窗缩回是两套计时器；返回取消待关闭，减少动态效果时仍保留清晰反馈。
- 数据区、平台明细、按钮、提示、菜单和它们之间的合理移动走廊属于一个逻辑悬浮区域。
- 逻辑悬浮走廊不等于鼠标拦截区域：透明空白仍应允许点击底下的桌面内容。
- 菜单、更多文本面板、拖动或刻意键盘聚焦可暂停自动收起；结束后重新计时。独立设置窗口保持打开不锁定叶片，鼠标点击数据也不固定展开。
- 悬浮展开不抢正在输入的窗口焦点；复制成功也不自动粘贴或切换前台应用。
- 在任务栏、缩放变化或拔掉显示器后重新约束位置，保证可以找回。
- 最大化/全屏软件的上层行为在原型验证；首版设置中提供临时隐藏入口。

### 6.2 具名复制与记事本

先填写按钮名称、可选短说明、选择内置图标，再点击“用记事本编辑”。每条文本用稳定 ID 对应独立 UTF-8 文件。内容保存后自动重新读取；另提供“重新读取”作为文件监听异常的退路。

未保存的记事本文字不参与复制。文件为空、被删除、编码错误、外部占用、剪贴板忙均有明确提示，不误报成功。保留换行，不擅自去空格。重命名不换文件 ID。首版只支持纯文本，图标选内置集合；不开放任意脚本和自制插件。

### 6.3 每日提醒

默认按本机时区的本地时间，每天一次；时段优惠固定使用 Asia/Shanghai。日常提醒和平台规则使用不同的时间语义。

应用在运行且电脑处于唤醒状态时触发通知；休眠/退出期间不保证提醒、不唤醒电脑。建议同一天恢复时补发未送达事项一次，并合并提示；跨天不堆积补发。按提醒 ID + 本地日期去重。系统勿扰可能阻止通知展示，浮窗应保留未读状态。开机启动为可选设置，不默认修改系统启动项。

## 7. 非功能需求与技术风险

- 本地单用户；后台网络不得阻塞动画和拖动。
- 三家查询独立成功或失败；异常不会使全部清空。
- 暂定轮询：展开 60 秒，收起 180 秒；来源有限流时服从其限制。进入展开仅在过期时请求。
- 单账号只允许一个刷新任务；短超时、有限退避、手动请求合并；退出和账号修改可取消。
- 凭据进入 Windows 凭据存储；配置、缓存与日志不含凭据。预存文本为用户主动编辑的本地明文文件。
- 当前个人使用交付的显示验收为本机单屏150%（2026-09-30用户修订）。100%／125%／200%和多屏布局实现及渲染检查保留，物理兼容性未验证；不以这些未验证环境扩大支持承诺。
- 先设性能验收目标，后在目标电脑测量；不在规划阶段承诺具体 CPU、内存或帧率结果。
- 最主要的不确定性：原生窗口命中/焦点、GLM 时间字段语义、Codex 授权来源、系统记事本保存事件、节假日数据。
