# 验证计划

状态：M1 核心已 Freeze；M2–M5 切片与 M6 验收进行中，当前39文件类型检查／Lint／112自动测试通过。历史验收定义仍保留，实际证据与开放门槛见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。日期：2026-09-30。  
与 SPEC 的 FR-01–FR-16 对应；测试按 PLAN 分阶段开展。

## 1. 验证分层

1. 纯领域规则：时间、窗口映射、空值、显示格式、状态转移、提醒去重。
2. 适配器契约：脱敏夹具、不完整字段、错误响应、请求取消与晚到结果。
3. 真实 Windows 交互：鼠标路径、透明区域、焦点、剪贴板、记事本、多屏/DPI。
4. 视觉对照：选定概念图与实现同尺寸/同状态截图；并由用户实际操作。
5. 长时间运行与发布包：空闲占用、失败退避、休眠恢复、干净系统。

2026-09-30用户明确当前百分比即可：本次个人使用以本机150%单屏作物理显示验收。下文其他DPI／双屏／拔屏保留为兼容检查目标，当前只有渲染／几何证据，不阻塞该设备交付，不宣称物理通过。

不为低风险文案改动机械加测试；优先覆盖可能使数据错误、操作失控或资料丢失的边界。不能用截图取代物理交互验证。

本轮新增：GLM 同类型双窗口以已核验 type/unit/number 区分，重排不串家，重复身份拒绝，未知／MCP／月度不映射成周。四个常用位分别复制独立正文，更多文本仍可访问；三平台＋七动作键盘顺序一致，第四位反馈不覆盖提醒图标。七球四边四档渲染通过，比例以实际 DPR 断言，不能把相对缩放倍数当成目标 DPI。

自动收起必须覆盖：独立设置保持打开、取消球点击、离开计时丢失后的重启、明确固定及键盘导航。收起态持续检测，不依赖 Windows Enter 事件；当前用户已确认三次悬浮／移出和取消点击正常，四复制球及 usage 49e7 候选正常路径也已实际确认。后续源码改变需匹配新候选，不沿用旧哈希作为新版本物理证明。

空闲性能直接观察已经运行的进程，不启动第二颗测试球；包括 Windows venv 的实际 Python 子进程及仅由应用启动的 Codex 子进程。采样期浮窗必须持续收起、无可见设置／辅助面板，否则不计为空闲通过。旧的 Enter 唤醒版本性能结果只作历史，不代表当前版本。

补充连续失败回归：三家同时保留旧值，连续五轮失败走30／60／120／300／300秒退避，手动更新、展开／收起及墙上时间跳变不能绕过。真实Qt的本地阻塞HTTP在10秒超时期间继续处理事件，超时后下一次读取成功，晚到旧响应不重新报成功。

## 5. 文本、记事本与提醒

T-COPY：多条命名/改名/排序/收藏稳定；长名称、重名、Unicode、空白/换行；剪贴板被占用；点击一次只复制指定内容；成功反馈对应实际写入；不自动粘贴。

T-NOTEPAD：新建后未保存、Ctrl+S 多次、多个标签、关闭而不保存、记事本进程复用、文件替换/删除/改编码。验证保存监听去抖与“重新读取”退路，正文不串项。

T-REMINDER：同日多条、禁用/改时间、系统勿扰、正常到点、应用退出、睡眠后同日恢复、跨日恢复、系统时间回拨、DST 缺失/重复时刻。验证日期幂等键、补发与未读状态；系统通知提交不冒充用户确认。

T-STORE：异常退出时配置不半写；保存失败明确；备份恢复；未知新版本只读提示；重复实例；账号凭据和日志脱敏；卸载/删除数据边界在发布前确定。

## 6. 视觉与可访问性

T-UI：
- 选定方向建立同状态参考图：正常、无账号、部分失败、低额度、优惠开启/关闭、提醒未读。
- 同一字号/描边/图标/间距规则覆盖主窗、文本列表、设置与提醒。
- 记录实际核心和整窗包围框；分别检查稳定展开态与有内部时间明细的临时态。预算见 DESIGN，不能忽略卫星球和注释占用。
- 常显的三家概要同时可读；真实小尺寸检查币种和额度。完整日期、倒计时、更新时间在悬浮/聚焦明细中检查；不只看放大的概念图。
- 核心符合已选的叶形轮廓，没有大透明矩形命中遮罩；半圈视觉目标与有效点击区域不重叠。
- 半球露出区保留所有必要状态；关键编码不藏在屏幕外。
- 收起球和卫星按钮在浅/深桌面背景均可见。
- 颜色以外还有图形/文案提示；不靠持续闪烁表达正常优惠。
- 文字对比度目标 4.5:1；平台名/正文目标 12–13 DIP，主数字 16–22 DIP；必要辅助文字不低于 12 DIP。重点检查窗口行/服务列对应、内部固定时间区、两个三单位倒计时与绝对时刻是否可读。
- 当前 7 个动作球视觉31 DIP、命中36 DIP，继承同一组件语言；M1 五球是历史基线。命中区不得叠加抢事件，尺寸与坐标按 DESIGN 第11节验收。
- 原型概念图里可能存在的进度长度、微文案或绝对比例误差，必须在真实原型按规范修正。

T-ACCESS：
- 点击/托盘/键盘可展开，不能只有鼠标悬浮一种方式。
- Tab 顺序清楚，Enter/Space 执行动作，Esc 关闭临时层，名称能被辅助技术读出。
- 对三平台和当前七动作逐项按 Tab、Shift+Tab、Enter、Space：聚焦高亮、叶片说明、实际结果和辅助说明指向同一项；复制成功需独立回读剪贴板，不能沿用先前内容制造假通过。
- 减少动态效果模式保留反馈，去掉空间移动。
- 焦点在窗口内部时不自动缩回。
- 四边未读提醒收起态均检查铃铛完整；顶部额外检查摆动各帧的描边不触碰窗口边界。

融合专项：
- 平台悬浮前后外轮廓和总尺寸完全相同，无外接面板或引线；概要与功能球坐标不变。
- Codex 列聚焦同时关联两行，缺失窗口不能从另一列借值；DeepSeek 焦点无配额重置。
- 默认取 Codex／GLM 四窗口最低已知剩余，同值先5h再Codex；恢复事件提供解释。无时间、旧数据、到点未确认都有明确回退，不因缺时间而隐藏已知额度。
- 静态字体测量不替代 Qt、中文回退、DPI 和真实鼠标验证。

### T-TIMER / T-MOTION

按 [倒计时与动效规格](docs/design/COUNTDOWN_MOTION.md) 的边界表检查：86400→86399、36000→35999、3600→3599、60→59、1→0、未知时间和非连续更新时间。

- 每个有效计时始终三单位，零值单位不被省略；跨24h整组切换，无旧数字/新单位混合。
- 10→9 时退出的字位有过渡，剩余字位、单位、表格和操作球不横向跳动；连续秒变化不重复动画未变的位。
- 动画中收到新 tick/新快照时合并到最新状态，不形成队列；借位涉及的数字同时更新。
- 休眠、时钟前后拨、隐藏后重开直接呈现当前时间，不能快速回放积压变化。
- 减少动态效果时仍有清楚反馈；未改变的数字保持静止。
- 实际操作录屏必须覆盖一次位数增减与一次单位制切换；静态图不算动画验收。
- 稳定停留后连续秒位必须继续完成160ms过渡，不能借首次详情入场动画冒充。GLM毫秒恢复时间在过渡尾部跨秒时也必须逐秒落定：展开250ms采样，一次过渡使用同一时刻，16ms短时补帧停止后不得留下常驻重绘。

## 7. 性能与交付证据

M1 记录原型动画帧耗时；M6 记录驻留 CPU、内存（含应用拥有的子进程）、异常恢复和网络频次，设备/系统/缩放必须一起记录。指标是设计目标，不是已测结果。

用户明确确认之前不写“UI Freeze”或“已达到商业上线质量”。交付必须区分：静态概念 / 可操作原型 / 已接真实数据 / 实际鼠标与多屏验证 / 用户验收。

参考：[W3C 文字对比度定义](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。这里只采用其对比度目标，不宣称桌面软件已经通过完整无障碍认证。
