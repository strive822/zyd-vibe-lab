# LibreTV

可在本机运行的视频聚合搜索与播放网页。应用源码位于 source/，Release 提供前端已构建的生产运行包。

## 功能一览

| 模块 | 可以做什么 |
| --- | --- |
| 聚合搜索 | 从已选择的点播源搜索片名，服务端聚合结果；部分来源失败时保留其他可用结果。 |
| 剧集播放 | 从详情选择剧集，支持快捷键、自动连播、移动端长按加速和换源测速。 |
| 跳过片段 | 标记片头、中段、片尾区间，同剧后续集可按设置自动跳过；可以撤销或调整标记。 |
| 进度与历史 | 在当前设备浏览器 IndexedDB 保存观看定位信息，不等于跨设备云同步。 |
| 本地缓存与下载 | 可按设置缓存后续分片，并从播放页下载本集；是否成功取决于资源与格式。 |
| 直播 / IPTV | 管理直播订阅，按分组筛选或搜索频道，支持 HLS 与 HTTP-FLV，以及频道收藏、M3U 导出。 |
| 来源与配置 | 管理源列表、订阅和配置导入导出，保留旧版历史迁移入口。 |
| 本机部署 | Release 为已构建的 Next.js 生产运行包，按安装说明准备 Node 与私有环境配置，无须日常重建前端。 |

典型用法是先配置自己有权访问的来源，再搜索、选集并播放。项目提供聚合与播放器，不提供影视资源或保证任意源可用。更多操作、环境变量和来源配置见 [应用详细说明](source/README.md)；本仓库的运行与验证入口见 [INSTALL.md](INSTALL.md)。

## 直接让 Agent 帮你使用

把下面这段话复制给具备联网、文件读写和运行能力的 Agent。
它应先读本项目 [INSTALL.md](INSTALL.md)，完成提示词授权的下载、核验与使用步骤。
只想保存文件时，把“安装/运行”改成“只下载，不安装、不启动”。

```text
安装并使用 https://github.com/strive822/zyd-vibe-lab 里的 libretv。先读取该项目 INSTALL.md，从固定 Release 下载对应成品并校验，按项目类型安装或启动；保留已有数据与配置。日常使用不克隆开发仓库、不重新构建前端；只下载时不安装或启动。
```

独立项目目录，保留原来的固定版本、个人使用配置和下载校验。无须获取其他项目。

当前固定 LibreTV 2.21.1 与 Node.js 24.22.1 LTS；源码快照包含已验证的依赖修复，见 [修复记录](SECURITY_PATCHES.md)。

- [Agent 下载与恢复](INSTALL.md)
- [来源与许可](THIRD_PARTY.md)
- `profile/`：启动入口、使用说明和许可副本；这是恢复材料，不能当成已安装程序。
- `assets.json`：仅包含本项目所需的固定下载来源、大小与 SHA-256。
- `restore.py`：只恢复本项目，目标必须是新目录。
