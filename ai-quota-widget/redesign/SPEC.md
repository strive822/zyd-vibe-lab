## 2. 用户、问题与成功标准

**首要用户**：在 Windows 上使用多个 AI 编程服务、需要频繁判断剩余额度的个人用户，以项目所有者的本机使用为当前场景。面向公开分发、收费运营和团队协作的需求尚未提出。

**要解决的问题**：额度分散在不同服务中，切换查询成本高；刷新失败、旧数据、账号变化和接口异常容易造成误判。产品应让用户快速看清各账号还剩多少、何时重置、数据是否可信，以及遇到错误后该做什么。

**成功标准**：

- 一眼区分 Codex/智谱的剩余额度和 DeepSeek 的余额，避免百分比方向或币种混淆。
- 同一账号没有重叠请求；一个慢账号或失败账号不拖住其他账号。
- 改名、隐藏、删除或更换 Key 后，账号身份、数据和扩展配置不会错配。
- 失效凭据、限流、网络错误、未知重置时间和部分异常数据均有明确表现。
- 查询不修改 Codex 登录文件，预览不访问真实账号，构建验收不强制关闭现有程序。

## 3. 产品流程与界面范围

### 核心使用流程

1. 启动程序，读取本地配置；无配置时提供首次设置入口，不因启动自动创建或覆盖配置。
2. 在设置中选择 Codex 登录文件、填写智谱/DeepSeek Key、调整显示和刷新参数；保存成功后应用，取消则丢弃草稿。
3. 对启用且可见的账号独立查询，在主窗显示额度或余额、重置时间及状态。
4. 用户查看数据，可右键手动刷新、隐藏账号、修改设置、调整置顶或开机自启。
5. 请求失败时保留同一账号的最后有效数据并标过期；按提示检查网络、等待冷却或在 Codex 客户端重新登录。
6. 关闭窗口时隐藏到托盘；托盘可恢复窗口；选择“退出”时停止调度并取消在途请求。

## 4. 功能需求与验收编号

| 编号 | 必须满足的目标行为 |
| --- | --- |
| FR-01 数据语义 | Codex、智谱显示剩余百分比：`100 - usedPercent`，只转换一次；有效百分比限制到 0–100。缺失窗口显示未知，不当作 0% 或 100%。DeepSeek 以原币种分行显示，不相加、不换汇。重置时间统一为秒时间戳进入模型，以本机时区展示；无法识别时显示未知。 |
| FR-02 账号身份 | 智谱使用稳定 `id`，不以数组下标、名称或 Key 作为持久身份；旧配置仅在内存补 ID，成功保存时写入。缺失或重复 ID 修复为不同值。账号未知字段随账号深拷贝和保存，删除、调序、改名、换 Key 均不转移给其他账号。Codex 和 DeepSeek 保持各一个配置槽位。 |
| FR-03 配置保护 | 首次缺文件允许创建；损坏 JSON、非对象根、已存在但类型错误的结构节点禁止覆盖。加载错误标志传递到设置草稿；即使磁盘文件后来被修复，也必须重新加载后再编辑。保存使用临时文件及替换，保留备份；保存失败明确反馈。加载不改写文件。 |
| FR-04 解析容错 | NaN、Infinity 和越界数字不得进入显示计算；旧配置中的 `ui.opacity` 被忽略，并在下一次保存时移除。无效重置时间为未知，格式化层也不能抛异常。金额直接解析为 decimal：非法总余额跳过该行，非法可选赠送余额记未知；合法币种继续显示并提示部分异常；全部无效时报告解析失败。 |
| FR-05 调度与外观设置 | 默认 10 秒，设置范围 10–3600 秒；每个可见且启用账号独立调度，同账号同时最多一个请求。连续点击不积攒请求。外观设置复用状态且不强制刷新；间隔变化从最近完成时间重算下一次到期时间，不能提前越过限流冷却。 |
| FR-06 请求生命周期 | 修改 Key、Codex 路径或智谱授权方式时清空旧凭据缓存，使旧代次失效并取消请求；旧请求确认结束后才能启动同槽位的新请求。隐藏账号停止新请求，允许在途完成；恢复时按到期条件刷新。删除、退出后迟到结果不得恢复账号或触碰已释放窗口。取消不计失败。 |
| FR-07 失败与冷却 | 同账号查询失败时保留最后有效数据并标过期。普通连续失败逐步退避；429 的等待不短于正常刷新间隔，服务端有效的更晚等待时间优先。手动刷新可跳过普通等待，不能跳过 429 冷却。智谱 429 中推算出的额度仍须标过期并冷却。 |
| FR-08 Codex 登录归属 | 只读取登录文件，不调用 OAuth 续期接口，不写 `auth.json` 或其临时/备份文件。401 时重读同一文件，仅在非空凭据或账号身份已变化后重试一次；仍失败提示在 Codex 官方客户端重新登录。403 独立报告访问失败。正常后续刷新重新读取登录；实际账号改变时清除前一账号缓存，失败结果也不能带出旧账号数据。 |
| FR-09 状态与交互 | 展示刷新中、需要登录、限流冷却、数据过期、请求失败、等待数据、余量提醒。错误/警告与数据有效性可同时存在；限流显示等待时间，保存失败说明未持久化。采用 DESIGN.md 的像素能源控制器布局与配色；保留 25%/10% 余量阈值，状态文本不可遮挡数值或操作入口。 |
| FR-10 预览隔离 | `--preview`、`--mock` 从合成配置启动，不读取正式配置和登录文件、不请求真实服务、不读写开机自启状态。预览设置只在本次预览生效，使用独立实例标识。 |
| FR-11 构建与替换 | 保留 Windows 命令提示符中的根构建入口；参数透传正式目录。无参数编译并测试，通过后尝试替换正式 exe；`--test-only` 不编译/替换应用 exe；`--stage-only` 不替换正式 exe。独立暂存产物路径必须明确；`.next.exe` 只作便捷别名，可能被旧进程占用。编译/测试失败返回非零，替换失败返回 3 并保留暂存产物，不强制终止进程。 |
| FR-12 资料与兼容 | 既有有效配置位置和未知字段保持可用。界面、日志、截图及报告不输出 Key、Token、原始响应或实际账号标识。正式实现位于 redesign，根目录保留构建入口；按用户明确清理要求移除早期实现和旧诊断资料，早期配置另存 local-backup，项目外内容不动。 |

### 状态呈现约束

| 情况 | 数据处理 | 用户应看到/能够做什么 |
| --- | --- | --- |
| 初次等待/未配置 | 无有效数据 | 显示占位与配置提示，不伪造额度 |
| 正常成功 | 更新本账号数据与成功时间 | 显示当前数值及重置时间 |
| 部分数据异常 | 保留此次合法数据 | 显示警告和未知字段；不是整个账号全部失败 |
| 请求失败且有旧数据 | 保留相同身份的旧数据 | 同时显示过期和失败原因；不能仅显示刚完成的刷新时刻造成误导 |
| 401 登录失效 | 同一账号的旧数据可标过期；换账号则清除 | 提示在 Codex 客户端重新登录，不在本工具内代办登录 |
| 429 限流 | 保留有效/推算数据并明确有效性 | 显示冷却剩余时间；操作不绕过限制 |
| 配置损坏/保存失败 | 损坏时停止请求和普通保存；普通保存失败保留原文件 | 损坏时整页只读/禁用编辑、增删及保存，保留修复说明、滚动与关闭；普通保存失败保留可编辑草稿。不能静默覆盖 |

主状态优先级沿用当前行为：刷新中 → 需要登录 → 冷却 → 数据过期 → 请求失败 → 等待数据 → 余量提醒；过期、警告等附加信息不能因主状态优先级而丢失。

## 5. 最小技术架构与数据边界

保持 Windows 本机单进程应用、C# / .NET Framework / WinForms 与线程池；不新增 Web 前端、服务端、数据库或消息队列。

| 层次 | 职责 | 输入/输出与一致性要求 |
| --- | --- | --- |
| 启动与生命周期 | 正式/预览实例隔离、加载配置、显示/退出 | 预览选择必须发生在正式配置加载之前；退出后不再接收状态更新 |
| UI | 主窗、设置草稿、菜单、托盘 | 只消费统一账号状态；只在 UI 线程更新控件；不自行决定网络重试 |
| 本机业务层 | 账号协调、请求去重、取消、代次、到期与冷却 | 请求持有不可变参数快照；完成时验证账号与代次；账号之间独立 |
| Provider 层 | 各平台只读 HTTP 查询、认证读取、响应解析 | 三个现有服务边界保留；读取失败返回结构化结果；不把远端错误原文交给 UI |
| 配置层 | JSON 读取、校验、草稿复制、兼容保存、备份 | 唯一持久化业务配置为本机 JSON；保护原文件及字段归属 |
| 运行状态 | 额度、余额、错误/警告、最后成功/完成时间、下次到期、冷却、请求状态 | 仅在内存；重启重新查询。旧缓存只属于同一账号身份 |
| 系统集成 | 用户级开机自启与窗口位置 | 仅正式模式显式操作；不以模拟验收修改真实系统状态 |
| 测试 | 合成响应、可控时钟/请求、临时文件、原生控件及手工 UAT | 离线证据、渲染证据、在线连通性和用户操作分别记录，不互相替代 |

最小内部契约：账号配置包含稳定身份及请求参数；请求快照包含账号键、Provider、凭据路径/Key、授权方式；结果包含成功/取消、HTTP 状态、安全错误/警告、登录要求、账号身份、可选冷却期限、额度窗口或分币种余额。内部类名可以局部调整，上述语义不能改变。没有供外部消费者调用的公共服务 API。

第三方依赖仅记录当前代码接入的 Codex 客户端额度接口、智谱额度接口和 DeepSeek 余额接口。本文不承诺其长期可用性或官方支持等级；接口变化应在 Provider 层处理。当前 HTTP 层具有连接/读写超时，验收仍需分别覆盖慢响应与取消，不能把两个局部超时之和描述成严格的请求总时限。

## 7. 技术风险

| --- | --- | --- |
| Codex 客户端接口或凭据格式变化 | 查询不可用 | 隔离 Provider；错误可恢复；发布候选单独记录真实只读验证，不以旧成功结果作保证 |

| 异常数据及金额精度 | 显示错误或窗口异常 | 有限数与时间范围校验、decimal、逐行容错、未知占位 |
| 状态颜色或时间标签误导 | 用户把旧数据当作新额度 | 持续显示过期/警告；明确全局完成时间语义；真实主流程 UAT |

| 构建目标被旧进程占用 | 误认新版已生效 | 独立暂存文件、明确输出、替换失败非零；不强制关闭已有实例 |
| 只有模拟/单次在线证据 | 误判发布就绪 | 在 PLAN 分开记录已知证据、待验收项与发布门槛 |

## 8. 功能边界与冻结项

本轮不增加服务商、历史用量统计、额度预测、自动切换账号/模型、付费运营、云端同步、远程管理、移动/Web 版本，不升级技术栈；整体视觉改为用户已确认的 DESIGN.md 像素规范。
