# 像素能源控制器 · Design Constitution v1

2026-09-25。用户已选择 A 方向；R4 按白色参考修订紧凑构图；R5 修订背景与能源色彩权重，U3/U4 完成紧凑上方设置和滚动指示线修复。**用户已认可视觉并确认 U4 实际滚动正常，独立 Critic 已审范围无未解决 P0/P1；完整 UI Freeze：YES。** 本规范替代旧架构基线中“保留现有外观”的约束，不改变 FR-01～FR-12 的业务与安全语义；正式程序替换是后续独立发布步骤。

## Product Personality / Design Identity

清晰、直接、精密的桌面资源仪器。用户快速读取账号余量、重置时间与数据有效性。核心记忆点：账号纵向排列、双轨分段能量条、右侧数字对齐。

Visual Concept：一台安静驻留桌面的像素资源仪器，以精确数字和高饱和分段能量条表达 AI 资源状态。

## Composition / Grid / Spacing

- 单一常驻窗口，连续底面，无卡片墙、折叠形态、标题栏宣传文字或常驻操作栏。
- R4 正常双账号以当前 144 DPI 下约 350×230 实际像素、面积 ±15% 为目标；不以诊断 1× 代替当前屏幕占用。主窗基础宽度 234 逻辑像素，按固定字体实际测量确保完整单行重置信息；长名称增高、多账号滚动、长金额可扩至 360 逻辑像素，受工作区限制。左右留白 8px。
- 主体高度动态测量，至多为屏幕工作区 75%，超出纵向滚动；底栏固定，左侧明确显示「最近请求结束」、右侧显示最近一次请求完成时间。该标签表达过程结束，不表达额度更新成功。首次等待、无可检查账号、配置损坏分别显示有意义的状态，不显示裸时间占位。
- 基础间距 4px，紧凑轨道允许 2px 微间距。账号名称与必要状态在上，每条额度为周期、数值/分段条、完整重置信息三列；百分比与分段条共用一列，重置信息不再独占跨全窗横行。
- 每轨道：周期标签、右对齐百分比与其下方横跨周期及数值两列的20段能量条、同轨道右侧的绝对重置时刻及倒计时。按实际余量填充，最后一段允许部分填充，不向上取整。
- DeepSeek 按币种完整显示余额，不构造缺少总容量依据的进度条。整数使用稳定的三位千位分隔；长金额独立成行，只在完整数字组之间换行，末尾一组整数与完整小数部分保持同一行，禁止省略有效数字。
- 长名称/警告动态换行，不能覆盖数字；不缩小文字以塞进固定高度。

## Typography

仅使用系统 Microsoft YaHei UI 与 Consolas，无外部字体依赖。

| 用途 | 主窗设备像素规则 / 设置100%基准 |
| --- | --- |
| 主窗数字 | Consolas Bold，max(20px, 16px × DPI倍率) |
| 账号名称 | Microsoft YaHei UI Bold，max(13px, 12px × DPI倍率) |
| 主窗标签/时间/状态 | Microsoft YaHei UI，max(12px, 10px × DPI倍率) |
| 底部时间 / 语义标签 | Consolas max(12px, 9px × DPI倍率) / Microsoft YaHei UI max(12px, 10px × DPI倍率) |
| 设置正文/输入/按钮 | Microsoft YaHei UI 14px |
| 设置分组标题 | Microsoft YaHei UI Bold 16px |

主窗上表为随 DPI 变化的设备像素规则，144 DPI 时正文15px、数字24px；100%下正文保持至少12px。设置与菜单不随此次主窗紧凑化缩小。字号固定，不因长内容溢出自动缩字。文字抗锯齿；形状对齐设备像素。测量和绘制使用相同的字体、宽度与换行规则。

## Component Language

- Radius=0；普通边界 1px，键盘焦点 2px；无装饰性阴影。
- Buttons：主按钮电青/深色文字；次按钮深色表面/边框；危险操作使用错误色文字。Hover 改底色、Active 即时边界反馈、Disabled 明确弱化、Focus 独立可见。无放大。
- Inputs：原生可聚焦输入，深色底、清楚标签、焦点电青边界；Error 附原因，Filled 不改变表面。Key 遮蔽。
- Containers：账号及设置分组使用连续的服务商色带，不增加外层卡片、边框或阴影；输入、菜单与提示可使用必要的独立表面。
- Navigation：沿用右键菜单、托盘、单页设置；无账号状态提供直接设置入口。菜单顺序保持兼容。
- Settings：单页滚动，固定保存/取消；保存失败显示持续内联提示，保留可编辑草稿；取消不改变源配置。配置损坏时整页仅供查看：文字字段只读且降低视觉权重，复选框、数值调整、账号增删及保存均禁用；修复说明、滚动查看和关闭保持可用。只读数值输入仍禁用编辑与箭头，但以次要文字色绘制当前值，不能沿用难读的系统暗灰字。
- Dialog：应用错误优先内联提示；保留系统窗口框架的可操作性，不另造装饰弹窗。
- 窗口层级：设置继承主窗当前置顶状态，并以主窗为模态所有者；设置在上方且与主窗不相交；空间不足时联合调整位置和可滚动区域，关闭后恢复主窗位置。取消保留原偏好，保存后应用用户选择的置顶状态。
- Iconography：像素网格上的功能性勾选/状态符号，统一粗细；不引入装饰资产。

## States / Interaction / Motion

| 状态 | 规则 |
| --- | --- |
| Normal | 服务商色轨道、数字和重置时间 |
| Loading | 首次无值显示 — 与等待说明；刷新保留旧值，只在本账号标记刷新中 |
| Empty | 显示无可见账号，提供设置按钮 |
| Stale | 保留同账号旧值，轨道中性化，持续显示数据过期与失败原因 |
| Login | 提示在 Codex 客户端重新登录 |
| Cooldown | 明确等待时间，手动操作不绕过冷却 |
| Partial | 合法字段继续显示，未知字段 —，附警告 |
| Error | 无旧值显示 —；有旧值同时显示过期；保存失败不关闭设置 |
| Config damage | 停止请求，整页锁定编辑与保存，明确仅供查看及修复后重启；保留滚动和关闭 |

主状态按现有优先级显示；主状态不能吞掉过期/警告，重复文案去重。只消费已有状态，不在 UI 发明重试策略。

因果反馈即时、逐帧变化，不新增定时装饰动画、模拟进度、滚动数字、扫描线；减少动态效果自然成立。刷新和普通展示不抢焦点。

## Responsive / Accessibility

- 仅 Windows 小窗口/不同工作区/DPI；无 Mobile/Tablet/Web 新产品。100/150/200% 缩放分别验收。
- 设置默认约 320x340 逻辑像素，右边缘与所属主窗对齐，并优先置于主窗正上方，两窗不相交；遇小工作区收缩并滚动，底部按钮始终可达；设置打开期间保持在所属主窗前方。
- Tab/Shift+Tab/Enter/Space/Esc；主窗菜单键或 Shift+F10 打开菜单，方向键/PageUp/PageDown/Home/End 滚动。
- 自绘数据暴露可读取的账号名称、数值、时间和状态；底部时间说明“最近一次请求完成，不代表所有账号成功”。
- 不只用颜色传达状态。高对比模式使用系统色。
- 悬浮窗不再绘制外围留白、外框或半透明边缘；服务商色带延伸到左右边界，底栏延伸到下边界。移除边缘透明度菜单、设置项及预览参数；旧配置字段读取时忽略，保存时删除。完整读数区始终不透明。

## DO / DON'T / Anti-Patterns

DO：准确数字优先、账号身份稳定、异常可解释、极端内容完整、像素刻度与排版一致、反馈对应真实操作。

DON'T：主要读数区回退为单一近黑底、颜色仅剩细线点缀、SaaS 卡片墙、卡中卡、圆角胶囊、渐变、Glow、玻璃、装饰阴影、背景网格、假代码、像素化中文、持续闪烁、假动画进度、DeepSeek 假百分比、用新时间掩盖旧数据。

## Delivery / Freeze

R5 后的用户结论为“视觉方面，我认为已经达到要求”。停止主动视觉迭代，保留紧凑尺寸、连续服务商色带、分段条及过期状态表达；不再添加装饰或安排例行视觉复审。只有实机验收发现具体缺陷时，才修复并提交同一状态的证据。候选身份、实机待验项和最终使用确认记录于 [UAT.md](UAT.md)。视觉认可不等同于完整操作验收。

主窗原型 → 真实模拟窗口截图 → 独立 Critic → 每轮修复前三项 → 设置/菜单 → Reduction → Polish → 用户验收。Critic 无 P0、主要 P1 已解决、适用自动检查通过且用户完成人工验收才可 UI Freeze。

Reduction 审查所有边框/标签/装饰，尝试删除至少 20% 的候选非必要元素，不为了比例删除必要信息。证据与未验证项记录于 UAT.md，不把离屏图伪装成桌面截图，不替换正在使用的正式程序。
