# 岛仔 Daozai 个人版

Windows 10/11 x64 顶部信息岛，基于 [Renly1994/xiaotang-daozai](https://github.com/Renly1994/xiaotang-daozai) v0.6.50 整合并修复。保留原作者署名与 MIT 许可；这里发布的是个人修改版。

## 功能一览

| 模块 | 可以做什么 |
| --- | --- |
| 常驻信息岛 | 在桌面顶部显示时间、电量、页面入口和 AI 额度；悬停展开，滚轮或箭头切页，可调整入口顺序与显示项目。 |
| 音乐与歌词 | 显示 Windows 媒体会话的歌曲、播放状态和进度，提供播放控制与歌词显示；信息取决于播放器是否提供媒体会话。 |
| 番茄专注 | 切换专注、休息阶段，开始、暂停或重置计时；收起时保留计时状态。 |
| 饮水 | 记录饮水量、查看当日目标进度，并按设置提醒。 |
| 待办 | 新建、编辑、完成和删除任务，可设置提醒；输入法确认候选字后，再按 Enter 保存。 |
| 日历与邮件 | 查看日程，按配置连接 CalDAV 与邮箱；显示邮件摘要、验证码和会议提示。需自行配置对应服务。 |
| 暂存站 | 收集文字、文件、文件夹和图片，支持网页图片与虚拟附件；卡片可点击使用，也可拖到其他软件或文件夹。拖出采用复制，保留暂存内容。 |
| AI 额度 | 提供 Claude、Kimi、Gemini、GLM 等八种来源的额度入口，按各来源支持的方式连接；不同服务的周期、余额和登录方式分别处理。 |
| 系统提示与位置 | 显示复制、网络、音量与输入状态提示；收起态直接横向拖岛并记住位置，设置可启用“双击右键居中”。 |

文字拖到编辑器时可作为正文，拖到文件夹时可作为文本文件；图片提供 PNG、位图和文件格式。目标软件决定接受哪些格式。原始文件只记录路径，文字、位图及虚拟附件保存在本地暂存副本中。关闭采集通道后不会继续从该通道入库。

## 下载与使用

[固定 Release](https://github.com/strive822/zyd-vibe-lab/releases/tag/daozai-v0.6.50-r6) 提供 三类内容拖出与输入法修正版安装器与 SHA256SUMS.txt。使用步骤见 [INSTALL.md](INSTALL.md)；源码、许可与开发记录保存在仓库。

包含音乐/歌词、专注、饮水、待办、日历、邮件、暂存站及八种 AI 额度来源。此次修正版支持整岛拖动与位置保存、顶栏饮水百分比/未完成待办数/日期或星期，并使用 GLM 开放平台的斜线 Z 标识。新增任何软件复制文字、图片或文件时的“已复制”系统提示；拖动展开顶栏不再有隐藏热区，快速起拖保留第一段位移；常规设置可开启“双击右键居中”（默认关闭，保留旧开关值）。暂存站支持拖入文字、文件和图片，包括网页图片与虚拟附件；文字卡片使用文档图标。穿透键 `·` 支持先按键再拖入或拖入后按键，松键恢复接收。展开后收起栏铃铛淡出，避免与页面设置齿轮重叠。图标排序在设置内进行。

安装包仍为 0.6.50；本个人版 EXE SHA-256 是 `95943FBB31D474A671B04ED208800BCF06CD059651E9750CB8B4F1BAA96502F1`，请用哈希区分同版本的上游包和较早个人构建。程序内“检查更新”只提示上游版本，不会自动覆盖个人版。

## 验证与维护

```powershell
python -m unittest discover -s packaging_tests -v
cargo test --locked --all-targets --features record -- --test-threads=1
cargo build --locked --release --bin daozai --target x86_64-pc-windows-msvc
./scripts/check-runtime.ps1 -Executable ./target/x86_64-pc-windows-msvc/release/daozai.exe
```

Rust stable、MSVC C++ 构建工具及 Windows SDK 用于源码构建；使用成品包不需要 Rust。测试必须单线程，真实账号相关 ignored 测试默认不运行。验证记录与边界见 [版本交付记录](docs/RELEASE-0.6.50-personal.md)。本轮 r6 的自动回归、原生验证和本机安装状态见交付记录；不以构建成功代替实际使用验证。Windows 10、其他真实 DPI/多屏及八家真实额度服务实连没有新增验收结论。
