# 岛仔 Daozai 个人版

Windows 10/11 x64 顶部信息岛，基于 [Renly1994/xiaotang-daozai](https://github.com/Renly1994/xiaotang-daozai) v0.6.66 整合。保留原作者署名与 MIT 许可；这里发布的是个人修改版。

## 功能一览

| 模块 | 可以做什么 |
| --- | --- |
| 常驻信息岛 | 在桌面顶部显示时间、电量、页面入口和 AI 额度；悬停展开，滚轮或箭头切页，可调整入口顺序与显示项目。 |
| 音乐与歌词 | 显示 Windows 媒体会话的歌曲、播放状态和进度，提供播放控制与歌词显示；信息取决于播放器是否提供媒体会话。 |
| 番茄专注 | 切换专注、休息阶段，开始、暂停或重置计时；收起时保留计时状态。 |
| 饮水 | 记录饮水量、查看当日目标进度，并按设置提醒。 |
| 待办 | 新建、编辑、完成和删除任务，可设置提醒；输入法确认候选字后，再按 Enter 保存。 |
| 日历与邮件 | 查看日程，按配置连接 CalDAV 与邮箱；显示邮件摘要、验证码和会议提示。需自行配置对应服务。 |
| 暂存站 | 收集文字、文件、文件夹和图片，支持网页图片与虚拟附件；卡片可点击使用，也可拖到其他软件或文件夹。拖出采用复制，保留暂存内容。 |
| AI 额度 | 提供 Claude、Kimi、Gemini、GLM、Kiro、豆包和中转站等额度入口，各服务按自己的周期、余额和连接方式展示。 |
| 系统提示与位置 | 显示复制、网络、音量与输入状态提示；收起态直接横向拖岛并记住位置，设置可启用“双击右键居中”。 |

文字拖到编辑器时可作为正文，拖到文件夹时可作为文本文件；图片提供 PNG、位图和文件格式。目标软件决定接受哪些格式。原始文件只记录路径，文字、位图及虚拟附件保存在本地暂存副本中。关闭采集通道后不会继续从该通道入库。

## 直接让 Agent 帮你使用

```text
安装并使用 https://github.com/strive822/zyd-vibe-lab 里的 daozai。先读取该项目 INSTALL.md，从固定 Release 下载对应成品并校验，按项目类型安装或启动；保留已有数据与配置。日常使用不克隆开发仓库、不重新构建前端；只下载时不安装或启动。
```

## 下载与使用

[安装与验证](INSTALL.md) 提供个人版 Windows 安装器及校验步骤。

升级会读取旧版的岛体位置和额度配置。胶囊展开过程中即可起拖。面板打开后，顶栏和各页内容区没有控件的位置也可起拖。沿停靠边移动，拖向其他屏幕边缘可切换停靠，松手后记住位置。可在设置中调整顶栏图标顺序与“双击右键居中”。天气可单独启用。

暂存站接收文字、文件、网页图片和虚拟附件，按住 `·` 可穿透到下层窗口。复制文字、图片或文件后的“已复制”提示由系统状态开关控制。

程序内的“检查更新”显示上游版本。个人版升级使用仓库 Release 的安装器。

## 验证与维护

```powershell
python -m unittest discover -s packaging_tests -v
cargo test --locked --all-targets --features record -- --test-threads=1
cargo build --locked --release --bin daozai --target x86_64-pc-windows-msvc
./scripts/check-runtime.ps1 -Executable ./target/x86_64-pc-windows-msvc/release/daozai.exe
```

Rust stable、MSVC C++ 构建工具及 Windows SDK 用于源码构建；使用成品包不需要 Rust。测试必须单线程，真实账号相关 ignored 测试默认不运行。此前 v0.6.50 个人版的验收见 [交付记录](docs/RELEASE-0.6.50-personal.md)。
