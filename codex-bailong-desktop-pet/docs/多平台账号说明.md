# 本地多平台额度扩展

保留白龙原有角色、动画、任务状态、日报与卡片尺寸，新增 GLM、DeepSeek、WorkBuddy、Antigravity 四个平台。按个人需求移除应用内聊天入口、聊天服务配置及聊天快捷动作；应用不再加载聊天模块。

双击根目录的 `启动白龙.cmd`。顶部 `CX / GLM / DS / WB / AG` 图标切换额度平台；点击原有额度卡片查看全部明细。缩小和极简模式跟随所选平台。额度、Token 图表和今日 Token 跟随所选平台切换，不借用其他平台数据。任务状态和重置公告仍来自 Codex。日报概览保留 Codex 会话指标；模型页默认汇总各平台实际用过的模型，并提供平台筛选。

设置 → 连接 → 其他平台账号：

- GLM：选择智谱国内站或 Z.ai 国际站，输入个人订阅套餐 API Key，保存并连接。显示真实剩余比例和接口提供的重置时间；接口未提供的到期时间不推算。
- DeepSeek：输入开放平台 API Key，保存并连接。显示真实币种、总余额、充值余额和赠送余额，不从本机 Token 估算。
- WorkBuddy：打开网页登录窗口，在官方网站完成登录。进入账号页面后自动连接，也可点击“已完成登录，连接当前账号”。查询保留登录浏览器的 User-Agent，兼容绑定浏览器标识的会话。如果账号使用 Bearer 登录，登录窗口会连接同站点的认证请求。过期后在同一入口重新登录。积分读取客户端使用的只读 `POST /billing/meter/get-user-resource-summary`，按 `Packages[].CycleRemainCapacity` 汇总；不签到、不兑换、不创建任务。
- Antigravity：首次在原应用登录后，直接读取 Windows 凭据管理器中的该应用登录状态并查询 Google 云端额度；关闭原应用也能每5秒刷新。访问令牌过期会自动续期，登录撤销后在原应用重新登录。云端暂不可用时，可回退到已运行的本机语言服务；不会启动 Antigravity。普通卡片仍最多显示两项，详情显示完整列表。

正常情况下每5秒分别刷新。查询未结束时不会叠加；服务返回限流时遵循 `Retry-After`，认证失效时降低重试频率。失败保留本次运行中上次有效数据并标注“上次记录”；更换账号会清空旧账号数据。刷新不发送推理请求，不新增额度不足提醒。

密钥与 WorkBuddy 查询凭据通过现有 Windows DPAPI 加密，保存在 `%LOCALAPPDATA%\BailongEnhanced\provider-secrets.json`，不会出现在设置备份、诊断或 Git 中。网页登录使用独立 Chromium 配置目录；不读取或修改原 WorkBuddy 的认证文件。

开发运行：`.venv\Scripts\python.exe app\enhanced.py`。本地 `.venv` 已安装依赖，动画来自已校验 SHA-256 的原仓库 Windows Release。此目录是个人源码运行版本，没有替换原仓库的公开安装包。

查询依据：

- GLM：[官方用量查询插件](https://github.com/zai-org/zai-coding-plugins/blob/main/plugins/glm-plan-usage/skills/usage-query-skill/scripts/query-usage.mjs)
- DeepSeek：[官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)
- WorkBuddy：本机安装客户端 `main/account.js` 的 `fetchResourceSummary` / `parseResourceSummary`。此接口未公开承诺兼容，客户端更新后可能需要适配。
- Antigravity：Google 云端 `loadCodeAssist` 获取当前账号项目，再使用该项目调用 `fetchAvailableModels` 读取 `quotaInfo`；禁止不带项目请求，避免虚假的满额结果。本机语言服务 `GetUserStatus` 作为回退，不使用旧 Windsurf 积分字段。内部接口变化时可能需要适配。


## Token 与交互口径

- Codex：本机增量日志，输入含缓存、输出含推理。
- GLM：官方 model-usage 接口，近31天按日数据及近一天小时明细，按模型统计；保存数字历史，不保存对话内容。
- DeepSeek：另在“管理 → 登录 DeepSeek 用量页（Token）”完成官网登录。只读 by_api_key/amount 接口；输入 = 缓存命中 + 未命中，输出另加。请求时间必须对齐本地自然日边界。只有每日数据时，今日入口显示近7天每日折线，明确标注“按日”，不虚构24小时分布。
- WorkBuddy：只统计本机 projects 下 JSONL 响应的明确 usage 计数，按消息去重。当前云端会话不提供可用 Token 计数，因此显示“未提供”，不会把上下文占用或积分当累计 Token。没有有效计数的模型不冒充已使用模型。
- Antigravity：本机 GetCascadeTrajectory 的 generatorMetadata.chatModel.usage。inputTokens + outputTokens；outputTokens 已含思考与回复，不再次相加。最终记录与 retryInfos 中相同 responseId/messageId 去重，仅显示实际响应模型。按会话修改时间缓存，仅重读变动会话；不保存提示词和回复内容。

中间长胶囊悬停180毫秒展开正常卡片；右侧额度圆悬停展开额度详情。移出卡片与原胶囊范围350毫秒后收回，操作设置和日报时保持展开。左侧快捷按钮仍点击执行，Codex 入口优先恢复已有真实窗口，否则激活安装包入口。

## 关闭 Antigravity 后查询额度（2026-10-25）

额度改为优先查询云端，不再以语言服务是否运行作为前提。只读取 Windows 凭据管理器的 `gemini:antigravity` 这一项；OAuth 客户端常量从本机安装的二进制动态读取，不写进源码。续期结果通过 Windows DPAPI 保存在桌宠自己的 `antigravity-cloud-auth.json`，不修改原应用的凭据。更换登录账号会使旧缓存失效。

最近一次有效额度另保存在用户数据目录的 `antigravity-quota-cache.json`；重启桌宠可先显示旧值并标明“上次额度、正在刷新”和时间。网络失败保留旧值；不会按时间推算额度恢复，也不把失败当0或100%。限流遵循服务器等待时间。缓存按登录凭据指纹隔离，不包含对话或邮箱。

云端模型列表可能比本机列表更多；相同显示名且相同额度、重置时间的别名合并。多个模型可能共享额度，不相加。云端返回的额度档位不等同于 Google One 订阅名称。此次在 Antigravity 进程不存在时已实际查到云端模型额度，查询前后均未启动原应用。Token 会话统计仍读取本机语言服务，本次只解除额度查询对应用运行的依赖。
