# 使用说明 — 三资产定投权重计算器

> 本地运行的定投权重计算工具。**纯计算，不交易、不联网持仓、不上传任何数据。**
> 根据纳斯达克100（NDX）、中证500（000905）、黄金现货（XAU）的最新行情，用 SMA800
> （近 800 个完整交易日收盘价均线）衡量相对高低，给出两套定投权重建议。

---

## 零、最省事：单文件 exe（免装 Python/Node）

项目已打包为单个可执行文件 **`backend/dist/DCA-Calculator.exe`**：

1. 双击 `DCA-Calculator.exe` 即启动前后端一体服务（自动同源提供页面与 /api）；
2. 浏览器打开 **http://127.0.0.1:8000**（注意是 8000，不是 3000）；
3. 无需安装 Python / Node，无需 .bat，适合直接分发给他人。

> 若 `dist/` 不存在或想自行重新打包，见 README「打包为单文件 exe」章节。

---

## 一、启动（推荐：桌面快捷方式）

1. 双击桌面 **`Start-DCA-Backend.bat`** → 启动后端（地址 `127.0.0.1:8000`）
2. 双击桌面 **`Start-DCA-Frontend.bat`** → 启动前端（地址 `localhost:3000`）
3. 浏览器打开 **http://localhost:3000**

> ⚠️ 顺序：**先后端、后前端**。后端命令行窗口启动后请保持打开，关掉它前端就拿不到数据。

若桌面没有这两个 .bat，可在项目目录手动启动：
```bat
:: 后端
cd backend
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

:: 前端（另开一个窗口）
cd frontend
npm run start
```

---

## 二、使用步骤

1. 打开页面后，会自动拉取行情并在顶部展示**三资产行情时间**（含各自收盘价时间）。
2. 页面**左右并排**显示两个模型的权重百分比与大数字卡片：
   - **左：C哥模型** —— `权重 ∝ 1/R`，R 越低（越便宜）权重越高，更直觉。
   - **右：严谨模型** —— 用 `-ln(R)` 与 γ=1.5 幂次平滑放大，分布通常更均衡。
3. 在「**总金额**」输入框填入本次定投的总金额（元）。
4. 下方立即给出每个资产的**金额分配**（2 位小数，合计严格等于你输入的金额）。
5. 修改金额只做本地重算、**不发任何网络请求**（行情成功抓取后内存缓存 60 秒）。

---

## 三、怎么读这两个模型

- 两个模型遵循同一原则：**某资产当前价相对其长期均线越低（越便宜），分配权重越高。**
- 差异在「惩罚曲线」：严谨模型对偏离的放大更平滑，权重分布通常比 C哥模型更均衡。
- **没有「哪个更对」**——它们是两种风险偏好的参考，请你结合自身策略取舍。

---

## 四、数据说明

- **行情源**：东方财富为主源，失败自动回退新浪 / 腾讯；黄金用现货报价。
- **SMA800**：近 800 个**完整交易日**收盘价均线；**盘中实时价不计入均线**，只用于计算
  `R = 现价 / SMA800`。
- **缓存**：成功抓取后内存缓存 60 秒，避免频繁请求行情接口。

## 五、常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 页面提示「当前无法完成计算…」 | 行情源全部不可用（断网 / 被限流）。稍等刷新，或检查网络后重试。 |
| 权重加起来不是 100%？ | 不会出现——程序保证两模型权重和 = 100%、金额和 = 输入。 |
| 改金额要等 / 数字跳动？ | 不会，改金额是纯本地重算，零网络请求。 |
| 打开页面空白 / 连不上？ | 确认后端已先启动且窗口未关闭；检查 `localhost:8000` 是否可访问。 |

---

## 六、停止

- 直接关闭后端 / 前端命令行窗口即可；
- 或在任务管理器结束 `python.exe`（后端）、`node.exe`（前端）。
