# Windows-MCP：来源与许可

- 上游 [CursorTouch/Windows-MCP](https://github.com/CursorTouch/Windows-MCP)，MIT；许可副本保留于 profile/LICENSE.md，恢复源码也保留原 LICENSE.md。
- 本轮前固定主线快照 87225657647929751c39740bd67abeb734dc07c6，项目声明 Windows-MCP 0.8.9，Python >=3.14。它跟踪已确认的主线渠道，位于官方 v0.8.9 发布提交之后。
- 上一完整基线 9ab92bca2772dfb53ae3ed4feb98dac22c5b3dea（0.8.8）。本快照更新桌面控制同意流程，并修复文件系统、显示索引、PowerShell 诊断等行为。
- 上游源码不在本仓库重复保存；assets.json 固定 codeload URL、字节数和 SHA-256，restore.py 下载并校验到全新目录。
- 本地修复记录于 [profile/personal-fixes.json](profile/personal-fixes.json)：取消请求时撤下授权提示和边框，输入回读只使用经核实仍聚焦的原控件。恢复程序逐文件核对修复前后的 SHA-256。
- 本地保留 Python 3.14.7、隔离安装目录、stdio、关闭匿名遥测和 watchdog 的启动器。桌面控制升级须先在隔离环境验收，再由用户终审实际宿主切换。

- 个人构建默认沿用 0.8.8 的 relaxed 桌面控制、10 秒用户空闲判定与 15 秒控制空闲释放。倒计时弹窗由部署者显式开启。释放或租约到期后旧同意作废。清空、粘贴和提交前确认输入焦点；从已确认落点到提交前收到 Win32 焦点变化事件时跳过 Enter。焦点事件计数随现有控制线程运行，不读取窗口内容。
- 已修正上游窗口枚举代码的缩进，恢复无边框窗口枚举。原始上游 ZIP 及最终定制文件均做哈希核对。
